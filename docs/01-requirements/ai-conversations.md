# 内置 AI 会话需求与验收

> 状态：Approved
> 最后更新：2026-10-12
> 关联：[交互设计](../02-design/ai-conversations.md)、[实现契约](../03-architecture/ai-conversations.md)、[验证记录](../04-quality/ai-conversations.md)

用户已确认原生聊天、模型配置和复用 MCP 权限的范围，并授权执行。目标用户是在 TinyShell 中排查和维护 SSH 主机的使用者；无需离开当前工作区即可向所选模型提问，授权后通过独立 SSH 工具执行操作。

## 2026-10-12 权限范围修订

原 AI-07/08/11 采用 AI 与外部 MCP 共用机器授权和模式。用户反馈已开启 AI 仍提示未授权，并明确设置应默认应用到所有 AI 对话，只有 MCP 需要选择机器。因此修订为：内置 AI 全局权限与外部 MCP 独立，每段对话保持单一绑定目标；设置按来源分 Tab，而非按终端 Tab 授权。SSH 执行、审批和审计继续复用同一引擎。已有内置开关及模式保留，外部授权列表不变。

## 验收标准

2026-10-12 展示修订：用户反馈工具结果展开按钮及底部状态重复、缺少操作层级，新增 AI-15。仅调整步骤呈现和关联元数据，执行、权限及审批规则不变。

2026-10-12 滚动修订：用户要求 SSE 响应期间持续显示最底部，替代此前仅在接近底部时跟随的行为。AI-10 增加流式输出和重新排版时持续跟随的验收；完成、停止或失败后可自由回看历史。

2026-10-12 预算修订：用户反馈达到工具调用上限后没有设置入口及继续/终止选项，确认“可配置预算、暂停选择、可选后台系统通知”方案并授权实施。替代 AI-10 中固定八轮工具交互的规则；新增 AI-16 至 AI-18。权限、逐次审批、重复结果及不确定结果保护不因继续而放宽。

2026-10-12 通知操作修订：用户要求系统通知提供允许/拒绝按钮以便快速处理。AI-18 的通知正文仍仅导航，新增原生按钮直接追加当前暂停预算或终止该轮；替代此前所有通知点击均只导航的限制，SSH 权限及逐次审批规则不变。

| 编号 | 可观察行为 |
| --- | --- |
| AI-01 | 头部纯净模式右侧的星光图标直接打开右侧对话，返回按钮进入本地历史；关闭面板保持生成和执行。 |
| AI-02 | AI 与 Docker 互斥显示，切换保存各自状态和未完成请求；AI 不扩大窗口，宽度默认 420px，可调 360–600px，终端剩余不足 480px 时覆盖显示。 |
| AI-03 | 无 SSH 时可以普通聊天。新对话选择当前 SSH；首次发送后固定目标，标签切换不改变目标。更换主机需要新对话。 |
| AI-04 | 历史可搜索、重命名、单条删除及清空，显示目标、消息数和时间；删除必须确认，先请求取消活动轮次。 |
| AI-05 | 设置新增 AI：多个 OpenAI 兼容 Provider、Base URL、API Key、模型、默认 Provider/模型和逐模型工具能力声明。模型可手输或主动刷新，发现列表可搜索并限高滚动。 |
| AI-06 | 测试连接只发送固定短消息；保存配置、打开页面不主动联网。改变地址时不得把旧地址的已存 Key 发往新地址。 |
| AI-07 | MCP 改称 MCP / CLI，内置 AI 与外部客户端分 Tab，独立启停和只读/受控/完全访问模式。AI 设置全局应用到所有对话，无需勾选机器；只有 MCP / CLI 选择机器。内置默认关闭，旧外部值不变。 |
| AI-08 | 开启内置 SSH 访问展示数据传输及权限说明；未启用、未绑定目标、目标配置变化或模型未声明工具能力时，不传出目标元信息或工具。外部客户端不能伪装成内置 AI。 |
| AI-09 | 受控操作复用 MCP 审批，待审批显示审阅入口；来自不同对话的任务和 SSH 会话隔离。只读不执行 Shell 命令或文件写入。 |
| AI-10 | 文本流逐步显示；SSE 响应期间每次刷新持续滚动至底部，较大分片、Markdown 重新排版及先前位于上方都不能使最新内容落在视口之外。完成、停止或失败后可自由回看历史。工具参数完整且合法后才执行；一段对话只有一轮活动生成，预算耗尽且需要下一次操作时暂停，不自动重试远程变更。 |
| AI-11 | 停止取消本轮网络和工具请求；变更 AI 模式或关闭内置访问撤销原 AI 能力及待审批；MCP 模式、机器授权与启停变更不撤销 AI 任务，AI 变更也不取消 MCP 任务。远程结果不确定时明确反馈。 |
| AI-12 | Key 和随机历史密钥使用系统凭据存储；本机历史采用认证加密和原子写入，不参与同步或导出，保留至人工删除。 |
| AI-13 | 凭据服务不可用时提供明确临时状态，已有密文保留；重启标记活动轮次中断，不重放工具。 |
| AI-14 | 中英文、原生主题、空态、错误、加载、停止、审批及后台活动提示完整；Markdown 和代码可复制，自动图片/HTML资源加载被禁用。 |
| AI-15 | 连续工具调用按顺序合并成可折叠的执行步骤组，显示本地化操作名、命令/路径摘要和准确状态；每步可展开参数与完整结果并复制。取消、中断、未执行及结果未知不显示成功；待确认步骤始终有审阅入口，折叠后仍可进入。聊天底部不再重复列出同一工具状态。 |
| AI-16 | 设置 → AI → 执行与提醒提供全局工具预算（默认 16，范围 1–128）及高级模型请求预算（默认 8，范围 1–64）。旧配置获得默认值；非法值不得保存；预算修改从下一用户轮生效。会话创建/查询不计入工具预算，缓存命中计入。 |
| AI-17 | 预算耗尽且还有待执行工具或模型请求时，保留当前轮并等待选择。前台所属窗口显示继续/终止弹窗，对话内保留入口；等待期间没有新模型请求或工具执行、没有处理动画。继续追加对应预算、从原位置恢复，不重放已完成操作；终止保留结果、不追加模型总结请求、不回滚远程变更。双击、旧通知、权限撤销或终止后的继续不得恢复其他轮次；重启标记中断。 |
| AI-18 | Windows/macOS 提供可选后台系统通知，默认关闭、每次暂停一次；仅通用文案，不能包含聊天、命令、路径或服务器信息。点击正文打开对应暂停对话；“允许继续”直接追加该次暂停的对应预算，“拒绝并终止”直接取消该轮，不要求再次确认。旧 token、重复点击及未知 action 不得处理其他暂停或轮次；关闭通知和超时仍保持暂停。测试通知按钮仅演示，不操作对话。macOS 首次主动开启或测试时申请通知权限，锁屏时继续按钮要求系统身份验证；发送失败、勿扰及不支持的平台不影响应用内提示。多窗口弹窗归属隔离。 |

首版不读取人工终端历史、选区或屏幕，不接收图片，不提供思考参数、计费管理或独立 CLI 产品。模型服务是否支持工具由用户显式声明，刷新列表不推断能力。实际验证证据与尚未验证范围仅记录在验证文档中。
