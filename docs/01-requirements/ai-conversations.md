# 内置 AI 会话需求与验收

> 状态：Approved
> 最后更新：2026-10-13
> 关联：[交互设计](../02-design/ai-conversations.md)、[实现契约](../03-architecture/ai-conversations.md)、[验证记录](../04-quality/ai-conversations.md)

用户已确认原生聊天、模型配置和复用 MCP 权限的范围，并授权执行。目标用户是在 TinyShell 中排查和维护 SSH 主机的使用者；无需离开当前工作区即可向所选模型提问，授权后通过独立 SSH 工具执行操作。

## 2026-10-12 权限范围修订

原 AI-07/08/11 采用 AI 与外部 MCP 共用机器授权和模式。用户反馈已开启 AI 仍提示未授权，并明确设置应默认应用到所有 AI 对话，只有 MCP 需要选择机器。因此修订为：内置 AI 全局权限与外部 MCP 独立，每段对话保持单一绑定目标；设置按来源分 Tab，而非按终端 Tab 授权。SSH 执行、审批和审计继续复用同一引擎。已有内置开关及模式保留，外部授权列表不变。

## 验收标准

2026-10-13 自动标题补充：用户要求第一次对话完成后，在后台异步生成 20 字以内、概括本次任务的标题，新增 AI-25。沿用首轮模型额外请求一次，实际用量计入当前会话。

2026-10-13 输入与权限修订：用户提供输入框参考图，明确“默认使用全局，手动选择优先”，并选择沿用现有只读/受控/完全访问语义。因此 AI-07 的全局模式改为对话默认值，新增 AI-24；AI-11 的全局撤销规则保留。参考图的对话/协作/托管名称、终端读取开关与思考参数不在本次范围。

2026-10-12 展示修订：用户反馈工具结果展开按钮及底部状态重复、缺少操作层级，新增 AI-15。仅调整步骤呈现和关联元数据，执行、权限及审批规则不变。

2026-10-12 滚动修订：用户要求 SSE 响应期间持续显示最底部，替代此前仅在接近底部时跟随的行为。AI-10 增加流式输出和重新排版时持续跟随的验收；完成、停止或失败后可自由回看历史。

2026-10-13 滚动补充：用户截图中等待工具确认时，底部内容仍停在视口之外。自动跟随扩展到工具执行、等待审批与预算暂停，替代此前只在 Generating 状态强制跟随的范围；整轮结束后的异步排版仍保持已有底部位置，用户主动上滑后保留阅读位置。用量栏与输入区保持独立高度，最新步骤、反馈或继续/终止入口应出现在聊天视口内。

2026-10-12 预算修订：用户反馈达到工具调用上限后没有设置入口及继续/终止选项，确认“可配置预算、暂停选择、可选后台系统通知”方案并授权实施。替代 AI-10 中固定八轮工具交互的规则；新增 AI-16 至 AI-18。权限、逐次审批、重复结果及不确定结果保护不因继续而放宽。

2026-10-12 通知操作修订：用户要求系统通知提供允许/拒绝按钮以便快速处理。AI-18 的通知正文仍仅导航，新增原生按钮直接追加当前暂停预算或终止该轮；替代此前所有通知点击均只导航的限制，SSH 权限及逐次审批规则不变。

2026-10-12 设置导航修订：用户提供快捷键子菜单截图，要求 AI 设置采用同样的分类导航。AI 下改为“模型服务 / 执行预算 / 通知提醒”三个具名分组与侧栏子菜单，替代此前把“执行与提醒”放在 Provider 表单上方的混排。两个预算直接展示，预算与通知各自保存，不改变对方的已保存配置。

| --- | --- |
| AI-01 | 头部纯净模式右侧的星光图标直接打开右侧对话，返回按钮进入本地历史；关闭面板保持生成和执行。 |
| AI-02 | AI 与 Docker 互斥显示，切换保存各自状态和未完成请求；AI 不扩大窗口，宽度默认 420px，可调 360–600px，终端剩余不足 480px 时覆盖显示。 |
| AI-03 | 无 SSH 时可以普通聊天。新对话选择当前 SSH；首次发送后固定目标，标签切换不改变目标。更换主机需要新对话。 |
| AI-04 | 历史可搜索、重命名、单条删除及清空，显示目标、消息数和时间；删除必须确认，先请求取消活动轮次。 |
| AI-05 | AI 设置侧栏提供“模型服务 / 执行预算 / 通知提醒”子菜单，点击沿用快捷键的分组定位交互。“模型服务”管理多个 OpenAI 兼容 Provider、Base URL、API Key、模型、默认 Provider/模型和逐模型工具能力声明。模型可手输或主动刷新，发现列表可搜索并限高滚动。 |
| AI-06 | 测试连接只发送固定短消息；保存配置、打开页面不主动联网。改变地址时不得把旧地址的已存 Key 发往新地址。 |
| AI-07 | MCP 改称 MCP / CLI，内置 AI 与外部客户端分 Tab，独立启停和只读/受控/完全访问模式。AI 全局模式作为所有对话的默认值，对话可单独覆盖；SSH 访问总开关仍作用于所有对话，无需勾选机器。只有 MCP / CLI 选择机器。内置默认关闭，旧外部值不变。 |
| AI-08 | 开启内置 SSH 访问展示数据传输及权限说明；未启用、未绑定目标、目标配置变化或模型未声明工具能力时，不传出目标元信息或工具。外部客户端不能伪装成内置 AI。 |
| AI-09 | 受控操作复用 MCP 审批，待审批显示审阅入口；来自不同对话的任务和 SSH 会话隔离。只读不执行 Shell 命令或文件写入。 |
| AI-10 | 文本流逐步显示；生成、工具执行、待审批及预算暂停期间每次刷新持续滚动至底部，正文不变时的工具区域加载、较大分片及重新排版都不能使最新反馈或操作入口落在聊天视口之外，用量与输入区不遮挡聊天。完成、停止或失败后，最后的异步排版保持已有底部位置，主动上滑可回看历史。工具参数完整且合法后才执行；一段对话只有一轮活动生成，预算耗尽且需要下一次操作时暂停，不自动重试远程变更。 |
| AI-11 | 停止取消本轮网络和工具请求；变更 AI 模式或关闭内置访问撤销原 AI 能力及待审批；MCP 模式、机器授权与启停变更不撤销 AI 任务，AI 变更也不取消 MCP 任务。远程结果不确定时明确反馈。 |
| AI-12 | API Key 在本地和云端均以云同步隐私密码加密，服务商、模型、预算、通知与 MCP 权限参与同步；未配置密码时新 Key 仅临时使用。历史主密钥使用系统凭据库，本机历史不参与同步或导出。2026-10-12 用户批准替代原“API Key 不同步”规则，详见[同步契约](../sync/ai-mcp-sync.md)。 |
| AI-13 | 凭据服务不可用时提供明确临时状态，已有密文保留；重启标记活动轮次中断，不重放工具。 |
| AI-14 | 中英文、原生主题、空态、错误、加载、停止、审批及后台活动提示完整；Markdown 和代码可复制，自动图片/HTML资源加载被禁用。 |
| AI-15 | 连续工具调用按顺序合并成可折叠的执行步骤组，显示本地化操作名、命令/路径摘要和准确状态；每步可展开参数与完整结果并复制。取消、中断、未执行及结果未知不显示成功；待确认步骤始终有审阅入口，折叠后仍可进入。聊天底部不再重复列出同一工具状态。 |
| AI-16 | 设置 → AI → 执行预算直接提供全局工具预算（默认 16，范围 1–128）及模型请求预算（默认 8，范围 1–64），不再藏于高级按钮。旧配置获得默认值；非法值不得保存；预算修改从下一用户轮生效。会话创建/查询不计入工具预算，缓存命中计入。通知开关与测试入口位于“通知提醒”，两组分别保存，保存预算不改通知偏好，保存通知不改预算。 |
| AI-17 | 预算耗尽且还有待执行工具或模型请求时，保留当前轮并等待选择。前台所属窗口显示继续/终止弹窗，对话内保留入口；等待期间没有新模型请求或工具执行、没有处理动画。继续追加对应预算、从原位置恢复，不重放已完成操作；终止保留结果、不追加模型总结请求、不回滚远程变更。双击、旧通知、权限撤销或终止后的继续不得恢复其他轮次；重启标记中断。 |
| AI-18 | Windows/macOS 提供可选后台系统通知，默认关闭、每次暂停一次；仅通用文案，不能包含聊天、命令、路径或服务器信息。点击正文打开对应暂停对话；“允许继续”直接追加该次暂停的对应预算，“拒绝并终止”直接取消该轮，不要求再次确认。旧 token、重复点击及未知 action 不得处理其他暂停或轮次；关闭通知和超时仍保持暂停。测试通知按钮仅演示，不操作对话。macOS 首次主动开启或测试时申请通知权限，锁屏时继续按钮要求系统身份验证；发送失败、勿扰及不支持的平台不影响应用内提示。多窗口弹窗归属隔离。 |

首版不读取人工终端历史、选区或屏幕，不接收图片，不提供思考参数、计费管理或独立 CLI 产品。模型服务是否支持工具由用户显式声明，刷新列表不推断能力。实际验证证据与尚未验证范围仅记录在验证文档中。

## 2026-10-12 统计与审计范围补充

用户批准[用量与审计设计](../02-design/ai-usage-and-audit.md)及详细脱敏加密留存，新增“统计与审计”设置入口；AI-05 原三个分组继续保留。以下是新验收范围，不代表运行验证已通过。

| 编号 | 可观察行为 |
| --- | --- |
| AI-19 | 本地对话按用户轮及模型请求累计服务报告的 Token，重复 usage 不重复计数，缺失和旧数据标为未知；设置连接测试独立记录，外部 MCP 不入聊天 Token。 |
| AI-20 | AI 与外部工具保存类型、用途来源、原始/有效参数、目标、状态、实际结果以及缓存/幂等/未执行事实，支持关联时间线、筛选、分页和脱敏导出。 |
| AI-21 | 权限、凭据和预算审批分别留请求与决定、审批快照、过期/失效和操作渠道；历史决定不能直接重放，当前待审阅入口保持原权限机制。 |
| AI-22 | 独立审计默认脱敏后本机加密保存 90 天，容量 512 MiB；密钥或记录不可持久化时不明文回退，阻止新的命令/写入，恢复存储不重试远端操作。 |
| AI-23 | 删除聊天、清理独立审计和清理旧摘要相互独立；旧摘要导入不伪造详情，用量和中断状态按实际可获得信息展示。 |
| AI-24 | 输入框顶部显示绑定目标及当前访问说明，底部显示模型、权限菜单和发送/停止。菜单有跟随全局、只读、受控执行、完全访问及各项说明/选中标记；新对话和旧历史默认跟随全局，显式选择仅作用当前对话并随加密历史保存，可恢复跟随。只读限制及受控逐次审批保持原语义；选择完全访问复用确认弹窗。活动轮含预算暂停不可切换；全局关闭、目标失效或模型无工具能力时不能凭覆盖获得 SSH 能力。长目标/模型名、360px 窄栏、中英文及主题不挤掉权限与停止入口。 |
| AI-25 | 新对话首次用户轮成功完成后，使用该轮 Provider/模型在后台命名一次，标题不超过 20 个 Unicode 字符、概括首条任务。命名不进入聊天正文、不阻塞下一轮；旧历史及手动标题保持，手动改名优先。首轮失败/取消不命名，命名失败保留临时标题且不自动重试。删除或关闭应用取消命名，不能复活已删会话。命名无工具权限，独立记录用途并将实际 Token 归入原会话及首轮。 |
| AI-26 | 待确认操作在所属聊天步骤内自动展示真实命令或文件修改预览，并可直接批准本次或拒绝，无需进入设置查找。折叠后审阅入口在当前对话展开；认证请求进入对应连接凭据编辑器。跨对话/目标、预览缺失、过期或已处理任务不能被批准；双击不能重复执行，失败有可见反馈。360px 窄栏仍可查看完整内容并触达按钮。 |

2026-10-13 审阅交互修订：用户要求减少弹窗及逐项查找。AI-09、AI-15 的审阅入口按 AI-26 改为聊天内逐次确认；设置中的全局任务页保留。不新增批量批准或持久授权，不修改权限、远端执行及审计规则。实现和原生验收状态见[质量记录](../04-quality/ai-conversations.md)。

## 2026-10-13 续聊建议范围补充

用户确认“回复下方”交互预览并授权实现：每轮完成后生成候选，提供添加到输入框与直接发送两种动作；另确认服务器名称左侧使用服务器图标。采用已说明的独立后台模型请求方案，新增全局开关及实际用量记录。以下补充不改变已有 SSH 权限、审批、预算暂停及目标绑定规则。

同日用户按实际界面修订操作分配：点击候选内容直接发送，去掉最右侧发送箭头，只保留添加图标。AI-27/28 以下列行为为准，替代首版“点击文字添加、箭头发送”的设计。

| 编号 | 可观察行为 |
| --- | --- |
| AI-27 | 每个正常结束的用户轮使用本轮 Provider/模型后台生成 0–3 条续聊建议，在最新回复下方纵向显示，随聊天滚动。候选是完整可见的单行请求文本，长文本允许换行，右侧仅保留添加图标；文字与图标均有对应动作的双语提示，可收起/展开。无有效候选、失败或超时不显示列表，不改变聊天完成状态、不阻塞输入、不自动重试。 |
| AI-28 | 点击候选文字直接发送该候选并保留已有草稿；点击右侧添加图标才将同一文本换行追加到已有草稿并聚焦末尾，不发送消息。直接发送与普通输入复用同一轮次入口、权限及审计；服务层原子验证来源会话、轮次与候选，新轮清空旧候选，双击、旧列表及迟到结果不能重复发送或串入下一轮。停止、删除及关闭应用取消候选请求。 |
| AI-29 | 设置 → AI → 续聊建议默认开启，说明每个成功轮额外一次模型请求和 Token 用量。关闭并保存后取消正在生成的候选、隐藏列表；开启不补发历史请求。开关随既有 AI 配置同步，候选与历史只在本机加密保存；请求审计标记“续聊建议生成”。服务器图标位于目标标签内名称左侧，长名称截断时图标仍可见，普通聊天保留原无目标图标。 |
