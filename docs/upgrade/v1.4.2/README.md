# TinyShell v1.4.2

> 发布日期：2026-08-07

## 版本概述

本版本修复 SFTP 底部面板中“目录树正常但当前目录文件列表始终空白”的问题。SFTP Home 路径现在会在进入应用状态前统一规范化，右侧列表直接使用当前路径对应的目录缓存；同时完善窄窗口分栏约束，并为空目录增加明确的图标和提示文案。

## 改进与修复

- 规范化服务端返回的 SFTP Home 目录路径：根目录保持 `/`，其他目录移除尾部 `/`。
- 统一 SFTP Home、当前路径和目录缓存使用的路径格式，避免 `/home/user` 与 `/home/user/` 形成不同缓存键。
- 右侧文件列表优先读取 `current_path` 对应的目录缓存，缓存尚未建立时兼容原有列表状态。
- 调整目录树和右侧文件列表的宽度、收缩及溢出约束，改善窄窗口和面板缩放时的可用空间分配。
- 空目录不再显示无反馈的空白区域，改为居中显示文件夹图标及“当前文件夹下暂时没有文件或文件夹”提示。
- 补充远程目录尾斜杠规范化测试，覆盖普通目录、根目录和连续斜杠。

## 行为与界面变化

- 连接到 Home 路径带尾斜杠的 SFTP 服务端时，右侧当前目录文件和文件夹可以正常显示。
- 当前目录没有可见内容时，右侧显示空目录提示；开启或关闭隐藏文件后，提示会随过滤结果自动更新。
- 左侧目录树默认宽度保持不变，但允许在较窄空间内收缩，并限制最大占用比例，避免挤压右侧列表。

## 配置与数据兼容性

- 配置文件、SSH/SFTP 会话、目录数据和远程文件格式均未变化，无需迁移。
- 路径规范化仅作用于应用运行时的远程目录状态，不会重命名、移动或修改服务器上的文件。
- 可直接回退到 `v1.4.1`，无需转换本地配置；但带尾斜杠 Home 路径的服务端可能再次出现右侧列表空白。

## 升级说明

Windows、macOS 和 Linux 用户均可直接覆盖安装并重启 TinyShell，无需额外配置或权限操作。已打开的 SSH/SFTP 会话需要重新连接，才能使用新的 Home 路径规范化逻辑。

## 破坏性变更与已知问题

没有已知的配置、数据或协议破坏性变更。本次发布按用户要求不在发布准备阶段重新运行测试，最终多平台安装包构建结果以 `v1.4.2` 标签触发的 GitHub Actions 为准。
