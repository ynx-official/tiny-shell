# TinyShell v1.0.3

> 发布日期：2026-07-20

## 版本概述

集中修复 macOS 在线更新与发布流程问题。

## 更新内容

- 修复 macOS 更新器崩溃。
- 移除不再适用的 Homebrew Cask 自动发布流程。
- 调整 GitHub Actions 在线升级流程。

## 升级说明

该版本未记录配置格式破坏性变更，可直接覆盖安装。升级前建议关闭正在运行的 TinyShell 窗口，并保留现有配置备份。
