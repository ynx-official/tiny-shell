# TinyShell v1.0.7

> 发布日期：2026-07-23

## 版本概述

发布线整理版本，汇入连接状态反馈、资源布局和界面动画改进。

## 更新内容

- 在终端输出中显示 SSH 连接状态。
- 优化资源侧栏、磁盘列表、进程面板和 SFTP 底栏布局。
- 支持调整常用命令详情面板宽度。
- 延续工作区、面板、标签和状态指示动画。

## 升级说明

该版本未记录配置格式破坏性变更，可直接覆盖安装。升级前建议关闭正在运行的 TinyShell 窗口，并保留现有配置备份。
