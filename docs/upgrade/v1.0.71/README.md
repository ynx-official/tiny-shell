# TinyShell v1.0.71

> 发布日期：2026-07-24

## 版本概述

将设置重构为独立窗口，并完善原生标签拖拽、多窗口和在线更新流程。

## 更新内容

- 设置界面迁移到独立系统窗口。
- 标签拖拽支持排序、分离、跨窗口合并和取消状态提示。
- 优化窗口启动、注册、聚焦和关闭清理，提升 Windows 稳定性。
- 改进在线更新设置、安装处理和中英文提示。

## 升级说明

该版本未记录配置格式破坏性变更，可直接覆盖安装。升级前建议关闭正在运行的 TinyShell 窗口，并保留现有配置备份。
