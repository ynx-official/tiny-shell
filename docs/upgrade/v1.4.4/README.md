# TinyShell v1.4.4

> 发布日期：2026-08-11

## 版本概述

本版本集中修复 SSH、终端和 SFTP 后端在连接取消、事件拥塞、超时和资源清理方面的稳定性问题，并加强 SSH 主机密钥校验与临时文件隔离。配置持久化、同步、连接管理和文件操作界面也同步完善了状态反馈。

## 改进与修复

- SSH 连接使用主机密钥校验和本地 `known_hosts` 管理，区分可信、未知和已变化的主机密钥。
- SSH 与 SFTP 连接支持更明确的取消、关闭、窗口尺寸同步、超时和异常结束路径。
- 终端输出和后端命令使用有界队列，避免高负载时无限制积压；远程系统信息采集增加输出上限和超时保护。
- 改进 SFTP 目录、文件编辑、传输和会话资源的生命周期管理，连接关闭时及时清理后台任务。
- 临时文件使用进程级隔离工作目录和独立任务目录，避免多窗口或并发任务互相删除临时数据。
- 改进配置持久化、同步、连接导入、托管密钥和窗口状态的异步更新及失败反馈。
- 补充和统一中英文用户可见文案，覆盖主机密钥、连接状态、远程信息和恢复失败等场景。

## 行为与界面变化

- 首次连接未记录过的 SSH 主机时，应用会要求确认服务器主机密钥；已记录但发生变化的密钥会阻止连接并提示风险。
- 关闭或取消连接后，相关终端、SFTP 和远程监控任务会进入明确的关闭状态，不再长期等待后台操作。
- 连接、导入、密钥和 SFTP 窗口在异步操作失败时保留上下文并显示错误反馈。

## 配置与数据兼容性

- 现有配置、会话、托管密钥和传输记录格式保持兼容，无需手工迁移。
- 新增的 SSH 主机密钥记录存储在应用配置目录的 `known_hosts` 文件中。
- 临时工作目录结构发生变化；旧临时目录不会被批量清理，升级后会在新的隔离目录中创建任务文件。

## 升级说明

Windows、macOS 和 Linux 用户可以直接覆盖安装。首次连接既有服务器时，如出现主机密钥确认，请核对服务器指纹后再接受。若服务器确实更换了密钥，应先通过可信渠道确认，再更新本地记录。

## 破坏性变更与已知问题

- 未知或已变化的 SSH 主机密钥不再被静默接受；自动化环境需要预先提供可信的 `known_hosts` 记录或完成首次确认。
- 本版本未改变配置和传输数据格式，但尚未执行真实远程服务器上的跨平台手工验收。
