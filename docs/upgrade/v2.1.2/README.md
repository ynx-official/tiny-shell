## 版本概述

本次补丁重点降低长 AI 对话的重复渲染、Markdown 解析与会话复制开销，并将 GitHub Release 和应用在线更新说明改为可直接阅读的独立纯文本。保留现有聊天、工具审批和历史存储规则，没有数据迁移。

## 改进与修复

### 长对话渲染

- 消息列表只布局当前可见范围及少量相邻内容，可变高度支持正文、代码和工具组；历史原文完整保留，仍可向上滚动查看。
- 已处理的 Markdown 复用缓存，最多保留 64 项、原文与处理文本合计不超过 4 MiB；超限只淘汰缓存，不截断正文或复制内容。图片和 HTML 仍沿用原资源阻断规则。
- 聊天模式只读取当前会话快照，输入、动画和布局等普通刷新复用未变化的数据；历史搜索继续使用完整历史。
- 工具活动按消息位置、调用 ID 和操作名建立索引，减少长记录中的重复扫描，旧活动仍按原顺序关联。
- 索引查询直接借用原会话中的调用 ID 和名称，修正临时字符串生命周期导致的 E0597/E0505 编译错误，不增加查询时的字符串复制。
- 工具组和续聊建议滚出视口后保留本次浏览的展开选择，切换会话时隔离内容和操作作用域。

### 在线更新说明

- 发布流程从本版本文档的“线上更新说明”部分导出 release-notes.txt，同时用于 GitHub Release 正文和更新清单指定的说明文件。
- 导出内容使用纯文本，不包含 Markdown 标记、仓库文档引用、内部验证记录或发布准备状态。缺少纯文本说明或混入受限格式时阻止发布。
- 应用的 GitHub HTML 回退来源优先读取同一纯文本附件；旧版本没有该附件时保留原历史兼容路径。

## 行为与界面变化

生成回复、执行工具、等待审批或预算暂停时继续跟随最新内容；本轮结束后，底部位置跟随迟到排版和续聊建议，主动上滑则保留阅读位置。发送、停止、复制消息/代码、工具批准/拒绝与续聊操作沿用原入口。

在线更新窗口和 Release 页面显示独立的纯文本说明，不再把内部 Markdown 文档整体搬到用户界面。

## 配置与数据兼容性

没有改变会话与审计存储、配置格式、密钥加密、同步协议、模型上下文或权限规则，无需迁移数据。更新清单仍为 schema_version=1，仅 notes_url 指向纯文本附件，v2.1.1 更新器已经支持任意合法 HTTPS 说明地址。

可回退至 v2.1.1 程序版本，无需本次专属回退迁移；回退后恢复旧聊天渲染方式。跨越 v2.0.0 的同步兼容性限制仍适用。

## 升级说明

可从 v2.1.1 直接覆盖安装。完全退出旧进程，安装或解压替换后重新启动；无需修改配置或重新导入聊天记录。

Windows 提供 x86_64 安装包和便携包；Linux 提供 x86_64 AppImage 和压缩包；macOS Apple Silicon 与 Intel 各提供基础版、RDP 版的安装包和便携包。三平台共享此次聊天与更新说明实现，没有新增平台专属迁移步骤。

## 破坏性变更与已知问题

没有新增破坏性配置或数据变化。单条超长正文、单个包含大量步骤的工具组仍整体布局，可能仍产生较高排版开销。本轮未进行帧率或内存性能采样，不宣称具体提升比例。

用户明确要求跳过本地测试，随后补充要求先通过本地构建再正式发布。本地 Windows release 构建已通过；未运行本地 Rust/Python 测试、Clippy 和原生应用。真实 AI/SSH 操作及多平台原生交互尚待手动验收，构建成功不代替功能与性能验证。

## 重点手动验收

1. AI → 历史打开数百至数千条消息的对话，快速上下滚动并输入草稿，检查响应、完整历史及终端操作是否正常。
2. 生成长回复、工具执行、审批和预算暂停时检查尾部及按钮可见；完成后上滑，再到达用量或续聊建议时保持阅读位置。
3. 展开工具结果和第三条建议，滚走再返回，检查展开状态、复制、批准/拒绝和候选操作；切换或删除对话不能串用内容。
4. 调整面板宽度、语言与深浅主题，检查文字、表格、代码和输入框无重叠或长期空白。
5. 旧版“设置 → 在线更新”检查 v2.1.2，更新内容应为纯文本，无井号标题、反引号、Markdown 链接或内部文档路径；升级后版本显示正确、原聊天记录和连接仍可使用。
