# TinyShell v1.1.12

> 发布日期：2026-07-30

## 版本概述

本版本集中重构独立 SSH 连接编辑器，重新组织连接、认证和代理配置流程，并将密钥认证统一收敛到应用内托管密钥。托管密钥选择器现在可以在独立编辑窗口中正常打开、确认并回填，同时会根据窗口可用宽度自适应，减少窄窗口下的内容裁切。

## 改进与修复

- 将独立连接编辑器拆分为“SSH 连接”和“代理服务器”两个页面，切换页面时保留已填写内容。
- SSH 页面按“常规”和“认证”分组，代理页面支持跟随全局、SOCKS5 和 HTTP，底部取消与保存操作保持固定。
- 连接类型、所属分组、认证方法和代理类型统一使用下拉交互，补齐右侧箭头定位及中英文标签。
- 认证方法精简为密码和密钥；密钥认证仅允许选择 TinyShell 已托管的密钥，不再在连接编辑器中填写自定义路径、内联私钥或口令。
- 为独立编辑窗口接入托管密钥选择状态，选择确认后直接回填当前编辑器。
- 补齐独立窗口的对话框渲染层，修复点击托管密钥后选择器不显示的问题。
- 托管密钥选择器根据当前窗口宽度设置安全边距，避免较窄窗口中左右内容被裁切。
- 修正更新下载进度值的百分比尺度，并将显示范围限制在 0% 至 100%。

## 行为与界面变化

- 新建或编辑 SSH/SFTP 连接时，左侧仅保留连接与代理两个入口，右侧表单内容可滚动。
- 未设置所属分组时明确显示“未选择分组”，不再复用“移出分组”操作文案。
- 密钥按钮是打开托管密钥选择器的普通动作按钮；未选择时显示选择提示，已选择时显示密钥名称和类型。
- 编辑旧 SSH Config 认证连接时，界面将其归并为密钥认证。
- 密钥选择器仍位于当前原生窗口的对话框层内，不会绘制到窗口边界之外。

## 配置与数据兼容性

- 会话、连接分组、托管密钥、代理、同步和 SFTP 的持久化数据格式均未变化，无需迁移。
- 已保存的密码认证和托管密钥认证连接可以直接继续编辑和保存。
- 旧的自定义密钥路径、内联私钥或 SSH Config 连接仍可由现有配置读取；若在新版连接编辑器中再次保存，需要先选择一个应用内托管密钥，保存后认证方式会收敛为托管密钥。
- 本版本未改变托管密钥文件的存储位置或加密方式，可以回退到 `v1.1.11`；但新版中已改存为托管密钥认证的连接，回退后仍会引用相同的托管密钥 ID。

## 升级说明

可以从 `v1.1.11` 或更早版本直接覆盖安装，无需转换配置。使用自定义路径、内联私钥或 SSH Config 认证的用户，在重新编辑这些连接前应先通过密钥管理器导入对应私钥。

Windows、macOS 和 Linux 均沿用原有配置目录与安装方式；本次窗口适配基于 GPUI 可用视口计算，不增加平台特定配置。

## 破坏性变更与已知问题

- 持久化数据格式没有破坏性变更。
- 连接编辑器不再提供自定义路径、内联私钥和 SSH Config 认证输入；相关旧连接在重新保存时必须改选托管密钥。这是有意收敛的安全与交互边界。
- GPUI 对话框不能绘制到原生窗口边界之外；窗口高度不足时仍受当前原生窗口可用空间限制。
- 本版本未增加独立的密钥选择原生窗口，以避免引入额外的窗口生命周期和跨窗口回填状态。
