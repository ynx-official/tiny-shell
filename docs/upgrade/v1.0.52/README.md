# TinyShell v1.0.52

> 发布日期：2026-07-22

## 版本概述

集中优化界面动画、SFTP 菜单、更新流程和 SSH 密钥管理。

## 更新内容

- 加入视图切换、面板展开、弹窗菜单和标签切换动画。
- 为 SSH 连接进度遮罩增加淡入效果。
- 优化 SFTP 右键菜单和应用交互工作流。
- 改进在线更新与 SSH 密钥管理。

## 升级说明

该版本未记录配置格式破坏性变更，可直接覆盖安装。升级前建议关闭正在运行的 TinyShell 窗口，并保留现有配置备份。
