# TinyShell v1.0.0

> 发布日期：2026-07-20

## 版本概述

首个正式版本，整合本地终端、SSH、SFTP、分屏、监控、主题和跨平台发布能力。

## 更新内容

- 提供本地终端与 SSH 会话管理，支持标签页和多 Pane 分屏。
- 提供 SFTP 多选、批量传输、拖拽上传、远程文本编辑和目录联动。
- 加入系统监控、主题切换、字体设置、快捷键管理和布局持久化。
- 完善 Windows、macOS、Linux 构建发布及中英文界面。

## 升级说明

该版本未记录配置格式破坏性变更，可直接覆盖安装。升级前建议关闭正在运行的 TinyShell 窗口，并保留现有配置备份。
