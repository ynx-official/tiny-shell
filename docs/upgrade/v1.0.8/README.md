# TinyShell v1.0.8

> 发布日期：2026-07-24

## 版本概述

继续完善独立设置窗口、在线更新和多窗口标签拖拽行为。

## 更新内容

- 改进在线更新设置、下载和安装处理。
- 将设置界面迁移到独立系统窗口。
- 延迟标签组分离，等待窗口回调完成后再转移会话。
- 优化应用界面及多窗口交互状态同步。

## 升级说明

该版本未记录配置格式破坏性变更，可直接覆盖安装。升级前建议关闭正在运行的 TinyShell 窗口，并保留现有配置备份。
