# TinyShell v1.5.12

> 发布日期：2026-08-20

## 版本概述

本版本继续优化 SFTP 和终端工作区交互，同时移除随应用分发的 Maple Mono 字体文件，改用系统字体、平台推荐等宽字体和字体回退机制。这样可以降低安装包资源负担，并让用户更容易使用本机已有的中文、Emoji 和 Nerd Font 字形。

## 改进与修复

- 优化 SFTP 快捷命令滚动、右键菜单、空状态和操作反馈。
- 改进终端会话管理、标签栏指示器、连接分组选择器和工作区交互。
- 移除内置 Maple Mono 字体资源及其启动时动态加载逻辑。
- 终端和界面字体设置增加系统默认、平台推荐等宽字体和可用字体回退判断。
- 终端文本渲染支持显式字体回退，改善中文、Emoji 和混合字形的显示连续性。
- SFTP 文本编辑、权限操作、主题和相关中英文文案继续完善。

## 行为与界面变化

- 应用默认使用系统 UI 字体；终端在 Windows、macOS 等平台选择推荐等宽字体，并从系统字体列表中选择具体字体。
- 旧配置中的 Maple Mono 字体偏好在不可用时显示为系统推荐字体，不会阻止启动或打开终端。
- 需要 Powerline/Nerd Font 图标时，用户需要自行安装并在终端字体设置中选择对应字体。
- SFTP 快捷命令和空目录区域提供更明确的滚动、右键和创建操作入口。

## 配置与数据兼容性

- 配置、会话、同步、托管密钥、SFTP 传输和工作区数据格式保持兼容，无需迁移。
- 旧字体配置使用兼容默认值回退；应用不会删除用户已安装的系统字体。
- 删除的是应用仓库中的内置字体资源，不影响用户操作系统字体目录。

## 升级说明

Windows、macOS 和 Linux 用户可以直接覆盖安装。升级后如需 Nerd Font 图标或特定中文字体，请在系统中安装字体并从终端设置选择；未选择时使用平台推荐字体。

## 破坏性变更与已知问题

- 不再提供 Maple Mono 内置字体；依赖该字体显示完整图标或字形的用户需要安装替代字体。
- 系统字体列表和中文/Emoji 回退效果取决于操作系统及已安装字体。
- 按用户要求跳过测试、静态检查和本地 release 构建，未执行跨平台手工验收。
