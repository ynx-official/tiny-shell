# TinyShell v1.5.13

> 发布日期：2026-08-20

## 版本概述

本版本优化 Windows 启动窗口的首帧定位与扩展动画，减少启动阶段窗口位置、尺寸和界面内容不同步造成的闪烁。配置、会话、同步和工作区数据格式保持兼容。

## 改进与修复

- Windows 首帧 loading 窗口显示在上次保存窗口所在显示器中央。
- 启动窗口扩展时同步动画移动位置和调整尺寸，结束后恢复保存的还原边界，再恢复最大化或全屏状态。
- 增加 Windows 原生窗口定位所需依赖与消息能力；macOS、Linux 继续使用原有跨平台回退路径。

## 行为与界面变化

Windows 启动时先显示居中的紧凑 loading 窗口，随后平滑移动并扩展到工作区窗口位置和尺寸。

## 配置与数据兼容性

配置、会话、同步、传输和工作区数据格式没有变化，无需迁移。

## 升级说明

可直接覆盖安装。首次启动时窗口会按新的启动动画呈现。

## 破坏性变更与已知问题

没有已知破坏性变更。Windows 原生窗口管理仍受系统窗口管理器和多显示器缩放设置影响。
