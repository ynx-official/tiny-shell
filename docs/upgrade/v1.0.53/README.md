# TinyShell v1.0.53

> 发布日期：2026-07-22

## 版本概述

新增常用命令管理，并系统改进连接管理与 SFTP 面板。

## 更新内容

- 支持常用命令分类、新增、编辑、删除和快速执行。
- 完善连接分组层级、排序、移动及右键操作。
- 支持 SFTP 面板视图切换及工具栏、底栏项目可见性配置。
- 调整设置、密钥管理、终端输入和中英文界面细节。

## 升级说明

该版本未记录配置格式破坏性变更，可直接覆盖安装。升级前建议关闭正在运行的 TinyShell 窗口，并保留现有配置备份。
