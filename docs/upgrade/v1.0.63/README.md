# TinyShell v1.0.63

> 发布日期：2026-07-23

## 版本概述

为工作区、面板、标签和状态切换加入统一动画反馈。

## 更新内容

- 新增工作区导航和面板切换过渡动画。
- 增强标签选中状态和连接状态指示动画。
- 为设置、连接筛选、SFTP 和常用命令视图加入平滑切换。
- 延续更新产物版本校验，避免安装过期文件。

## 升级说明

该版本未记录配置格式破坏性变更，可直接覆盖安装。升级前建议关闭正在运行的 TinyShell 窗口，并保留现有配置备份。
