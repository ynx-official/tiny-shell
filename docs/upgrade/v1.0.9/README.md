# TinyShell v1.0.9

> 发布日期：2026-07-24

## 版本概述

统一 macOS 应用元数据模板并增强 pkg 更新器。

## 更新内容

- 打包脚本与更新器共享同一份 Info.plist 模板。
- 增强 macOS pkg 更新路径和应用包处理。
- 减少打包配置与运行时更新配置不一致的风险。

## 升级说明

该版本未记录配置格式破坏性变更，可直接覆盖安装。升级前建议关闭正在运行的 TinyShell 窗口，并保留现有配置备份。
