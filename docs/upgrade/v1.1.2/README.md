# TinyShell v1.1.2

> 发布日期：2026-07-25

## 版本概述

增强应用与发布标签的一致性校验，并简化发布环境依赖。

## 更新内容

- 更新器增加更严格的版本一致性验证。
- 发布流程校验 Git 标签与 Cargo.toml 版本。
- 移除发布版本门禁对 Python 的依赖。

## 升级说明

该版本未记录配置格式破坏性变更，可直接覆盖安装。升级前建议关闭正在运行的 TinyShell 窗口，并保留现有配置备份。
