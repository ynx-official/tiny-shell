# TinyShell v1.3.1

> 发布日期：2026-08-03

## 版本概述

本版本针对 FinalShell 导入后的首次连接流程和快速连接窗口进行补丁级优化。缺少凭据的连接现在可以稳定打开紧凑的补录窗口，密码与托管密钥可以互相切换；快速连接分组的展开、尺寸和状态记忆也更加可靠。

## 改进与修复

- 快速连接窗口缩小默认尺寸，分组箭头与文件夹名称统一对齐，并记忆上次展开状态。
- 缺少密码或密钥的连接双击后稳定打开凭据窗口，补录窗口支持密码与托管密钥切换。
- 密钥选择器打开时从当前配置刷新托管密钥，窄窗口下自适应显示名称、类型和指纹。
- 没有实际密钥的密钥认证连接统一归一为 `KeyPending`，避免把未配置密钥误认为可直接连接。
- 修复分组收起后的文字重叠、切换动画闪烁和延迟关闭父窗口导致凭据窗口不显示的问题。

## 行为与界面变化

- 快速连接窗口首次打开时分组默认收起；再次打开会恢复上次展开状态。
- 点击分组箭头负责展开或收起，点击分组名称负责选择分组。
- 凭据补录窗口仅显示连接摘要和认证区域，不再展示完整 SSH 编辑侧栏。

## 配置与数据兼容性

- 配置格式保持兼容，无需手工迁移。
- 读取或保存配置时，缺少实际托管密钥、私钥路径或内联私钥的 `auth = Key` 会转换为 `KeyPending`。
- 已有密码、托管密钥和私钥内容不会因 FinalShell 元数据覆盖而被清空。

## 升级说明

可直接覆盖安装并重启 TinyShell。升级后首次双击待补凭据连接时，按提示输入密码或选择托管密钥即可。

## 破坏性变更与已知问题

没有已知破坏性变更。`KeyPending` 连接在完成密钥选择前不能直接建立 SSH/SFTP 连接。
