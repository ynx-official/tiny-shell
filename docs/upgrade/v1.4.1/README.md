# TinyShell v1.4.1

> 发布日期：2026-08-06

## 版本概述

本版本对更新状态提示、连接管理器分组布局和托管密钥对话框流程进行补丁级改进。发现新版本时，更新弹窗使用更紧凑的脉冲动画；连接分组行减少冗余元素并改善窄窗口对齐；密钥选择和导入流程改用明确的对话框替换语义，避免被已有 SSH 对话框阻塞。

## 改进与修复

- 为更新状态提示增加紧凑尺寸的脉冲图标，并与原有标准尺寸实现共享动画逻辑。
- 更新弹窗仅在发现可用新版本时显示紧凑脉冲动画；错误、已是最新版本和其他状态继续使用静态状态点。
- 简化连接管理器分组行结构，统一文件夹图标和分组名称的垂直对齐，并允许名称区域在窄窗口中正确收缩。
- 移除分组行末尾重复的展开状态字符，避免异常字符和多余的视觉提示。
- 托管密钥选择器和密钥导入窗口改用各自明确的对话框类型，并替换当前对话框，不再错误复用新建 SSH 对话框类型。

## 行为与界面变化

- 检测到新版本时，更新弹窗的状态卡片显示较小的脉冲动画；侧栏和其他现有更新提示保持原有尺寸。
- 连接管理器分组仍通过文件夹图标表达展开状态，不再在行末额外显示符号。
- 从 SSH 编辑流程打开托管密钥选择器或导入窗口时，当前对话框会被目标窗口直接替换，返回与确认流程更稳定。

## 配置与数据兼容性

- 配置文件路径、会话、连接分组、托管密钥、同步、SFTP 和终端偏好格式均未变化，无需迁移。
- 本版本只调整 UI 渲染和对话框协调方式，不改变密钥存储、加密格式或更新协议。
- 可直接回退到 `v1.4.0`，无需转换配置数据。

## 升级说明

Windows、macOS 和 Linux 用户均可直接覆盖安装并重启 TinyShell，无需额外迁移或权限操作。
