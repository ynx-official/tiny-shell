# TinyShell v1.2.0

> 发布日期：2026-07-31

## 版本概述

本版本为命令管理器加入覆盖常用 Linux 工作流的内置命令库，并同步改进终端补全、长列表滚动和命令内容展示。更新日志发布链路也改为交付独立的用户可见日志资产，应用内只展示真实功能、行为、兼容性和限制变化。同时修复 SFTP 进入子目录时面板重复淡入闪烁的问题。

## 新功能

- 首次初始化命令管理器时提供 8 个分类、125 条常用 Linux 命令，覆盖文件与目录、查看文件、查找与文本、权限与用户、系统与进程、网络与远程、压缩与解压及效率工具。
- 每条内置命令包含稳定 ID、简短名称、具体命令和用途备注，并根据中文或英文界面选择对应名称与备注。
- 终端输入补全继续按照实际命令前缀匹配，输入至少两个字符后最多展示 6 个候选，并显示简短名称和用途说明。

## 改进与修复

- 新用户首次启动直接获得全部内置分类和命令；升级用户保留已有自定义分类与命令，并按具体命令内容去重补齐内置项。
- 内置命令只按模板版本合并一次，用户后续修改或删除的内容不会在每次启动时被强制还原。
- 命令管理器使用独立、持久的滚动状态，长命令列表可以稳定垂直滚动并显示滚动条。
- 分类数量使用固定右侧槽位、明确的文本右对齐和等宽字体，避免切换分类时数字位置抖动。
- 命令列表不再重复显示所属分类，改为上方显示简短名称、下方让具体命令占据整行宽度；超长内容仍可通过悬浮提示查看完整文本。
- 应用内更新日志保留版本标题、发布日期、版本概述和真实用户变化，过滤验证结果、变更依据及返回版本总览等审计或导航内容。
- 发布流水线生成独立的 `release-notes.md` 并随安装资产上传，`update-manifest.json` 直接引用该用户日志资产，同时避免将其误识别为安装包。
- 修复 SFTP 进入子目录时目录内容变化重复触发整个面板淡入动画的问题；动画现在只随面板视图或最小化状态变化。

## 行为与界面变化

- 命令管理器左侧仍负责分类筛选，右侧列表改为名称与命令内容的上下结构，不再显示冗余的所属分类文字和双列表头。
- 双击命令执行、单击选择、右键编辑、复制、移动分类和删除等原有操作保持不变。
- “全部命令”和普通分类的数量采用相同的固定右对齐规则，分类切换不会改变数字的右边界。
- 更新弹窗不再展示发布验证记录和代码比较依据，但仍保留用户判断是否升级所需的版本、日期、功能、兼容性和已知限制信息。

## 配置与数据兼容性

- 配置文件新增 `quick_commands_builtin_version` 字段，用于记录内置命令模板是否已合并；旧配置缺少该字段时按 `0` 处理并执行一次初始化。
- 已有自定义分类、命令名称、备注和命令内容会被保留；仅当具体命令字符串与内置项重复时跳过对应内置命令。
- 现有会话、连接、托管密钥、同步、终端和 SFTP 数据格式不受影响，无需手工迁移。
- 回退到 `v1.1.12` 时，已经写入配置的内置命令仍会作为普通快捷命令保留；旧版本会忽略新增的模板版本字段。

## 升级说明

可以从 `v1.1.12` 或更早版本直接覆盖安装。首次启动新版本时，应用会自动完成一次内置命令合并并保存配置，无需用户操作。

Windows、macOS 和 Linux 的配置目录与安装方式保持不变。内置模板面向 Linux 终端和远程主机；在 Windows 本地终端或缺少对应工具的系统中，命令是否可执行取决于当前 shell 和已安装程序。

## 破坏性变更与已知问题

- 本版本没有破坏性配置迁移。
- 内置命令不会检测远程系统发行版或工具可用性；例如部分网络、压缩或效率工具需要目标系统预先安装。
- 按具体命令内容去重意味着：若用户已保存完全相同的命令，内置版本的名称和备注不会覆盖用户定义。
- 用户主动删除或修改内置命令后不会自动恢复；后续需要恢复时可手工创建，或等待新的内置模板版本执行增量补齐。
