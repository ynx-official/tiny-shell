# TinyShell v1.0.5

> 发布日期：2026-07-21

## 版本概述

增强应用内更新交互，并将完整设置编辑能力整合到设置页面。

## 更新内容

- 新增交互式软件更新对话框。
- 在设置页面嵌入完整配置编辑器。
- 完善更新检查、确认和安装反馈流程。

## 升级说明

该版本未记录配置格式破坏性变更，可直接覆盖安装。升级前建议关闭正在运行的 TinyShell 窗口，并保留现有配置备份。
