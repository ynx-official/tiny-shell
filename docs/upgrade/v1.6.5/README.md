# TinyShell v1.6.5

> 发布日期：2026-09-30

## 版本概述

本版本增强终端命令输入和补全体验，增加 SFTP 终端路径同步偏好持久化，并改进会话管理、同步处理和工作区界面布局。

## 新功能

- 新增终端命令补全和快速命令头部。
- 记录命令使用情况，为命令补全提供更贴近用户习惯的结果。
- 新增 SFTP 终端路径同步偏好，并持久化相关设置。

## 改进与修复

- 改进会话管理、连接工作流、SFTP 操作和同步合并处理。
- 优化侧边栏品牌、SFTP 目录树和工作区界面布局。
- 完善本地化与配置持久化边界。

## 行为与界面变化

终端输入区域提供更明确的命令补全入口；SFTP 与终端之间的路径同步行为可按偏好保持；侧边栏和目录树的视觉对齐更加一致。

## 配置与数据兼容性

既有配置、会话、同步和工作区数据保持兼容。新增设置和命令使用记录由应用自动创建，无需手动迁移。

## 升级说明

可直接覆盖安装。升级后重新打开应用即可使用新增命令补全和路径同步设置。

## 破坏性变更与已知问题

未发现破坏性变更。由于本次按要求跳过本地测试、静态检查和 release 构建，跨平台产物仍需由标签流水线验证。

## 验证结果

- 已更新版本号、`Cargo.lock`、变更日志、升级总览和版本详情。
