# TinyShell v1.4.5

> 发布日期：2026-03-14

## 版本概述

本版本将同步基线接入真实同步成功边界，确保本地记录的远端快照只在对应下载、合并、落盘或上传流程完整成功后更新。同步目标继续使用现有远端 v2 格式和方向化合并语义，避免提前切换协议造成兼容性风险。

## 改进与修复

- 为 WebDAV 和 S3 同步目标生成稳定、隔离的目标标识，避免不同同步目标共享错误基线。
- 在成功下载并完成本地配置落盘后保存远端 payload、revision 和 ETag，下载、迁移、合并或落盘失败时不推进基线。
- 在条件上传成功并完成本地状态保存后更新基线，上传失败或基线写入失败时不报告完整成功。
- 隐私密码重置成功后保存精确的远端快照、ETag 和新密码状态，避免后续同步从过期基线继续计算。
- 本地同步状态继续使用硬件绑定加密存储，并按同步目标隔离保存。

## 配置与数据兼容性

- 远端同步数据继续使用现有 v2 格式，无需手工迁移远端文件。
- 旧版本没有同步基线时，会在下一次完整成功的下载、上传或隐私密码重置后自动建立本地基线。
- 本地同步基线存储在应用配置目录中，并使用当前设备硬件密钥加密；更换设备不会解密旧设备的基线文件。

## 升级说明

Windows、macOS 和 Linux 用户可以直接覆盖安装。升级后首次成功同步会建立或刷新对应目标的本地基线；如果同步过程失败，应用会保留此前可用的基线，不需要用户手工清理状态文件。

## 破坏性变更与已知问题

- 本版本不切换远端协议，不改变现有方向化合并语义。
- 按发布要求跳过 `cargo test`，因此本版本未声明测试套件通过；真实远程服务和跨平台手工验收仍需单独执行。
