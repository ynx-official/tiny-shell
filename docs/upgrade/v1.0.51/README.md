# TinyShell v1.0.51

> 发布日期：2026-07-21

## 版本概述

增强 SFTP 导航、标签会话控制和交互偏好持久化。

## 更新内容

- 新增可导航的 SFTP 目录树。
- 新增标签页右键会话控制菜单。
- 持久化交互偏好且不阻塞 UI。
- 优化拖拽后标签组分离时机和 SFTP 树样式。

## 升级说明

该版本未记录配置格式破坏性变更，可直接覆盖安装。升级前建议关闭正在运行的 TinyShell 窗口，并保留现有配置备份。
