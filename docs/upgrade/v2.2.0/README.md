## 版本概述

本次版本改进 AI 模型服务配置、操作结果提示和确认弹窗。厂商编辑与全局默认模型分别管理，保存前补齐默认组合选择；异步操作完成后在发起窗口显示结果；关闭窗口使用更紧凑的均衡比例，确认后切换为中性等待提示，并保持各区域位置稳定。

## 新功能与改进

### AI 厂商与默认模型

- 模型服务设置采用可搜索的厂商列表与配置编辑区，顶部集中选择唯一的默认厂商和模型。选择要编辑的厂商不会自动改变默认组合；切换默认厂商后需要重新选择模型，避免同名模型混淆。
- 厂商配置与默认组合一起保存。只添加模型而未选择默认组合时，保存会打开联动选择表单；取消保留编辑，完成选择后一起保存。
- 停用默认厂商、移除默认模型或删除默认厂商时校验替代组合。有其他可用厂商时，需要先保存有效替代；删除最后一个可用厂商允许清空默认。
- 发现模型列表标记并禁用已添加项，鼠标和键盘确认均不能重复添加；移除后可重新添加，每次添加后重置选择框。
- 新增模型默认启用工具调用，可按模型能力取消；已有模型的能力设置保持原值。已添加模型跟随页面滚动，长名称换行，高级选项可折叠。

### 操作反馈

- 成功、失败、警告和信息提示采用一致的状态标题与具体结果，补齐 AI 设置、代理保存、主动复制和 SFTP 文件操作的反馈。
- AI 保存、删除、清除 Key、连接测试、刷新模型与偏好保存使用各请求独立的完成回执；代理设置也等待实际持久化完成，避免将排队误报为保存成功。
- 提示属于原发起窗口或会话工作区。原窗口关闭后不会跳到其他窗口；SFTP 新建、重命名、改权限和删除按明确结果事件反馈，同时保留状态栏及列表刷新。
- AI 消息、代码、工具步骤、审计详情和 SFTP 路径的主动复制提示成功；通知不重复展示复制内容，自动选区复制及远程剪贴板同步保持静默。
- 输入校验失败保留草稿和对话框，连接及传输进度继续使用原有状态界面。

### 确认弹窗

- 默认宽度调整为 360px、内边距 20px、标题 16px、正文及按钮文字 13px；按钮高 32px，取消和执行的最小宽度分别为 76px、88px。长标签、大字号和窄窗口继续自适应。
- 确认关闭后，底部按钮替换为左对齐的旋转图标与“关闭中…”状态行，移除红色加载按钮和不可用的取消按钮。
- 确认前预留两种状态所需的标题、正文及底部空间，切换时保持外框、正文起点和底部位置稳定；等待期间重复点击或键盘输入不会重复执行关闭。

## 行为与界面变化

设置 → AI → 模型服务先在顶部选择默认组合，再编辑厂商并保存；全局默认仅影响新建会话，既有会话保持原厂商和模型。首次只添加模型时会出现默认选择引导。

关闭确认继续允许取消；接受关闭后等待实际同步、保存和清理结束，再退出所属窗口。普通删除和覆盖等共用确认弹窗也使用新比例，原有确认与取消语义保持不变。

## 配置与数据兼容性

沿用既有 AI 设置 JSON、默认厂商和厂商内部默认模型字段，不新增数据迁移。旧配置中的有效全局默认可继续读取；非全局厂商的旧默认字段仅作为兼容信息保留。连接、密钥加密、历史会话、审计存储、配置路径及云同步协议没有格式变化。

可回退到 v2.1.4，无专属迁移步骤；旧版将恢复原设置界面、确认弹窗和提示行为。已保存的默认组合仍采用兼容字段。升级前可按既有流程备份配置。

## 升级说明

可从 v2.1.4 直接覆盖安装。完全退出旧进程，安装或替换程序后重新启动。检查 AI 全局默认组合；对于不支持工具调用的新增模型，取消对应选项后保存。

Windows 提供 x86_64 安装包和便携包；Linux 提供 x86_64 AppImage 和压缩包；macOS Apple Silicon、Intel 均提供基础版与 RDP 版安装包和便携包。本次界面及设置规则跨平台一致，远程桌面后端和各平台安装方式保持不变。

## 破坏性变更与已知问题

没有新增破坏性配置或数据变化。有其他可用厂商时，删除或停用当前默认厂商需要先保存替代组合；这是为避免新会话失去有效默认模型增加的校验。

原生窗口视觉、真实网络请求、实际 SFTP 文件操作和多平台交互尚未手动验收；自动测试及构建不能替代这些验证。原有两个凭据库实机测试和手动性能基准仍按既有配置忽略。

## 线上更新说明

TinyShell v2.2.0

AI 模型服务设置升级为可搜索的厂商列表与独立配置区，顶部统一选择默认厂商和模型。只添加模型但没有选择默认时，保存会引导完成选择；新默认只影响新建会话。

已添加模型会在发现列表中标记，防止重复添加；模型列表和长名称展示更完整。新增模型默认启用工具调用，不支持时可取消勾选，已有模型设置保持不变。

保存、删除、复制和 SFTP 文件操作补齐统一结果提示。异步操作在实际完成后反馈，提示保留在原窗口或所属会话工作区。

关闭确认弹窗采用更均衡的大小和按钮比例。确认后显示中性旋转图标和关闭中状态，前后布局保持稳定，等待同步和清理完成后退出。

可从 v2.1.4 直接覆盖安装，退出旧版本后重新启动即可。连接、密钥、会话历史和同步数据无需迁移。

## 重点手动验收

1. 主窗口关闭：先取消，再确认；观察等待状态没有跳动，重复点击及 Enter、Escape 不重复触发关闭；真实同步完成后窗口退出。
2. 在中英文、深浅主题、大字号和窄窗口下检查确认弹窗；普通删除确认可取消，长说明可滚动，按钮不遮挡。
3. AI 模型服务：添加两个厂商及同名模型，切换默认厂商后重新选模型并保存；新会话使用新组合，旧会话保持原配置，重启后保存有效。
4. 仅添加模型后保存：完成默认选择引导；取消保留草稿。验证发现列表重复添加保护、长模型名称及页面滚动。
5. 保存和复制后查看原窗口提示；用测试目录执行 SFTP 新建、重命名和删除，核对成功与失败提示、状态栏及列表刷新。
