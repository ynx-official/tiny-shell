# TinyShell v1.1.8

> 发布日期：2026-07-30

## 版本概述

本版本集中提升终端工作区的显示密度和输入效率：可以切换紧凑终端布局、临时进入纯净工作区，并通过工具栏快速分屏；SSH 终端还会根据已保存的常用命令提供前缀补全。

## 新功能

- 在设置中增加“标准 / 紧凑”终端展示风格；紧凑模式会调整终端指标和周边布局，在相同窗口空间内显示更多内容。
- 增加工作区纯净模式，临时隐藏侧边栏和 SFTP 底栏，并使用更紧凑的内容间距；退出后恢复普通工作区状态。
- 在终端工具栏中增加向右、向下分屏入口，并统一提供 SFTP 展开/收起、复制和粘贴等高频操作。
- 为普通 SSH 终端增加常用命令补全：输入至少两个字符后，最多展示 6 个不含参数占位符的前缀匹配项；支持方向键选择、`Tab` 补全首项、`Enter` 接受已选项、`Esc` 关闭。

## 改进与修复

- 补全候选默认保持未选择状态，避免按 `Enter` 时意外执行首个建议；只有显式选择后，`Enter` 才会接受候选。
- 补全状态按 SSH 标签隔离，并在切换到终端备用屏幕、断开连接或输入不可追踪控制字符时清理，避免影响 Vim、top 等全屏程序。
- 终端展示风格会随设置保存，并参与多窗口设置合并。

## 行为与界面变化

- 设置页面新增“终端展示风格”，默认仍为“标准”，现有用户升级后的初始显示不变。
- 标签栏新增纯净模式按钮；纯净模式中的 SFTP 展开状态与普通模式分离，不会覆盖原有 SFTP 面板偏好。
- 原工作区底部快捷操作调整为悬浮终端工具栏，分屏操作可明确选择向右或向下。
- SSH 命令补全来源于“常用命令”配置，仅进行大小写不敏感的命令前缀匹配，不会补全包含 `[p1]` 至 `[p5]` 参数模板的命令。

## 配置与数据兼容性

- 配置新增 `terminal_display_style` 字段；旧配置缺少该字段时自动使用 `standard`，无需手工迁移。
- 连接、分组、密钥、同步、SFTP、会话和快捷键数据格式未发生破坏性变化。
- 纯净模式和命令补全状态属于运行时工作区状态，不新增需要迁移的持久化数据。
- 可回退到 `v1.1.7`；旧版本会忽略本版本新增且无法识别的展示偏好，不影响核心连接数据。

## 升级说明

可以直接覆盖安装。升级前建议关闭正在运行的 TinyShell 窗口并保留现有配置备份；升级后如需更高显示密度，可在设置中将终端展示风格切换为“紧凑”。

## 破坏性变更与已知问题

- 本版本没有已知的破坏性配置或数据变更。
- 命令补全当前仅用于普通 SSH 终端，不在本地终端或 SSH 备用屏幕中显示。
- `Tab` 在补全列表可见时优先接受首个候选；需要向终端发送原始 `Tab` 时，可先按 `Esc` 关闭补全列表。
