## 版本概述

本版本改善 AI 对话从提问、执行审阅到下一步操作的流程。新会话首轮完成后生成短标题，每轮成功回复后可显示续聊建议；对话可单独选择权限，待确认工具在聊天中直接展示真实预览并批准或拒绝。输入区整合目标、用量、模型与权限，建议列表更加紧凑，工具确认期间继续跟随最新内容。本次按用户要求本地跳过测试，云端保留现有发布工具测试，构建与发布资料校验继续执行。

## 新功能

### 自动标题与续聊建议

- 新会话先使用首条任务前 20 字作为临时标题，首轮成功后用该轮模型异步生成 20 字以内的单行标题。命名不占用主回复或输入状态；手动改名、删除及晚到结果均有独立校验，旧历史和重启不补发命名。
- 正常完成回复后，后台生成最多三条相关建议。默认显示前两条，第三条通过“更多建议”展开；整组可收起。点击候选文字直接发送该候选并保留原草稿，点击右侧添加图标只追加到草稿并聚焦输入框。
- 设置 → AI → 续聊建议新增默认开启的开关。关闭并保存会取消待完成生成、隐藏候选；重新开启只影响后续成功回复。
- 自动命名额外请求模型一次；开启续聊建议时，每轮成功结束也会额外请求一次模型。实际用量计入所属会话，并在审计中分别标记用途，独立于主执行预算。辅助请求不提供 SSH 工具，不主动发送额外目标元信息；失败不重试、不改变主回复状态。

### 对话权限与聊天内审批

- 输入区可为当前对话选择跟随全局、只读、受控或完全访问；新对话默认跟随全局，不继承另一对话的覆盖。
- 完全访问需要显式确认。运行、审批和预算暂停期间禁止修改；内置 AI 的 SSH 总开关仍能撤销所有对话的访问。
- 待确认工具自动展开对应步骤，直接展示命令账号、目标、完整命令和工作目录，或文件路径、原内容及待写入内容，提供批准/拒绝入口。
- 批准只作用本次操作，后续操作仍逐次审批。失效、身份不匹配、缺少预览或需要登录凭据的任务不提供普通批准入口；设置页的任务和审计记录继续可用。

## 改进与修复

- 将用量放入输入框顶部，使用 k/M/B 缩写，悬停显示精确统计，点击打开当前会话审计。目标和模型长名称保留全文提示，优先保证权限及发送/停止入口可达。
- 区分已确认用量、进行中等待返回和结束后未知，真实零值保持已确认；后续回复不会清除历史未知记录。未完整统计显示 `*`，旧历史缺记录不当作已确认零。
- 候选采用统一整行背景及悬停反馈，文字和图标区域不再形成单独高亮块；最小行高调整为 32px，长文本自然换行。
- 将聊天跟随扩展到工具执行、审批与预算暂停；整轮结束后允许主动上滑回看，输入区和聊天视口分别限制高度。
- 拆分 AI 渲染子树并隔离大型临时 UI 值，针对 Windows 未优化构建打开面板退出时发现的栈占用风险进行修订。未捕获运行时转储，本次不把该修订当作退出问题已通过实机复验。

## 行为与界面变化

输入框顶部显示服务器目标及紧凑用量，底部显示模型、权限和发送/停止。跟随权限会显示实际模式，SSH 关闭、无目标、目标变化或模型不支持工具时显示对应原因。建议在回复下方进入聊天滚动内容，右侧仅保留添加图标；审批直接在工具步骤中进行。

默认开启的续聊建议会产生额外模型请求。需要控制该项用量时，可关闭设置 → AI → 续聊建议；标题请求也会计入会话用量与审计，不显示为额外聊天消息。

## 配置与数据兼容性

- 无数据库迁移、历史重写或加密算法变化。新版读取旧历史时，对话权限缺字段默认为跟随全局，标题缺字段保留原名，候选缺字段为空；未完成的后台生成在重启后标记失败或中断，不重放请求。
- 对话权限覆盖、标题及候选随本机加密历史保存，不参与云同步；API Key 继续使用云同步隐私密码保护。
- `execution.followup_suggestions` 加入既有 AI 设置，缺字段默认开启，复用 v4 配置同步。旧 v4 客户端可能在保存设置时丢失此偏好，共享同步目标的设备建议统一更新。
- 回退至 v2.0.0 时，新字段可能被忽略或在保存时丢失，当前对话的权限覆盖将不再生效，应核对全局模式；先备份本地配置、加密历史和云端同步文件。v2.1.0 没有将同步协议再次升级，v1.x 仍不能读取 v4 同步文件。

## 升级说明

可从 v2.0.0 覆盖安装，完全退出旧进程后重启。检查 AI 续聊建议开关和当前对话权限；共享 WebDAV/S3 配置的设备统一更新，避免旧客户端覆盖新增偏好。

Windows 继续提供安装包与便携包；Linux 提供 AppImage 与压缩包；macOS Apple Silicon 和 Intel 各自提供基础版与 RDP 版安装包及便携包。源码构建沿用 Rust 1.96.1 及既有平台依赖。

## 破坏性变更与已知问题

本版本没有新增必须执行的数据迁移或同步协议升级。旧客户端不理解新增设置和对话字段，回退与混用限制见上一节。

最新建议、对话权限、聊天审批、滚动和渲染修订的回归已加入源码，本次本地跳过 Rust 测试和原生应用运行。云端发布工具测试及构建成功不代表真实模型兼容、费用、工具审批、Windows 面板退出或多平台原生布局已经验证，按下表验收。

## 重点手动验收

| 入口与操作 | 预期与异常检查 |
| --- | --- |
| 新建 AI 对话，首轮成功后立即继续或手动改名；再删除生成中的对话 | 标题异步更新且不阻塞输入，手动名称不被覆盖，删除后不复活；审计列出额外命名请求。 |
| 回复后输入草稿，点击候选文字和添加图标；展开第三条、收起整组 | 文字只发送候选并保留草稿，图标只追加；默认两条，展开不误发，连续点击不能重复开始轮次。 |
| 关闭续聊建议并保存，生成中开始下一轮或删除对话，再重启 | 旧候选不覆盖新轮、不恢复删除，不重放请求；关闭后没有新增候选请求，重新开启不补发历史。 |
| 选择对话只读/受控/完全访问，切回跟随；关闭全局 SSH | 只改变当前对话，完全访问需确认；运行中不能修改，总开关仍撤销访问，其他对话不受覆盖影响。 |
| 工具请求命令或文件写入，展开预览并批准/拒绝；重复点击或停止后点击 | 预览完整且属于当前任务，批准只执行一次，拒绝不执行，失效任务不能批准；设置任务与审计保持一致。 |
| 同一会话连续回复，包含缺失及零用量；360px 侧栏、深浅主题和长文本 | 等待与未知分别累计，真实零值不丢失；精确提示和审计入口可用，候选完整换行，工具确认及发送/停止可达。 |
| Windows 主窗口重复打开 AI、历史和权限菜单；另复核原有 SSH/SFTP 与云同步 | 面板不退出，布局和导航正常；聊天结束后上滑不被拉回，保存的设置与既有同步域无回归。 |
