# TinyShell v1.3.2

> 发布日期：2026-08-05

## 版本概述

本版本集中整理连接管理、会话配置、SFTP 和同步模块的职责边界，减少重复状态和无效代码，同时改善连接管理器的分组交互、布局和后台状态处理。发布工作流也增加了版本详情缺失时的备用 Release Notes 生成路径。

## 改进与修复

- 重构连接管理器、会话配置、SFTP 和同步模块，拆分过大的实现并收敛模块可见性。
- 优化连接管理器分组与会话行渲染，减少参数传递，改善分组缩进、展开交互和主机列宽度。
- 统一标签查找、SFTP 工作区状态和传输上下文，降低重复状态导致的不一致。
- 强化配置持久化、配置同步、后台事件路由和异步任务的生命周期边界，减少过期任务覆盖新状态的风险。
- 清理不再使用的操作、死代码和不必要的 Clippy 抑制，保持错误路径和状态转换更明确。
- 发布工作流优先使用版本详情生成 Release Notes；详情缺失时使用提交历史生成备用说明，避免发布流程因单一说明来源失败。

## 行为与界面变化

- 连接管理器的分组行增加更清晰的层级缩进和双击交互，主机列使用更紧凑的默认宽度。
- SFTP、配置保存、同步和后台事件的高频状态更新继续由各自模块处理，上层应用只负责协调。
- 应用用户可见的主要连接、终端和 SFTP 操作保持原有工作流。

## 配置与数据兼容性

- 现有 TinyShell 配置、连接、分组、密钥、同步、SFTP 和终端偏好数据格式保持兼容，无需手工迁移。
- 本版本不改变配置文件路径、加密边界或同步协议；可直接回退到 `v1.3.1`。

## 升级说明

可直接覆盖安装并重启 TinyShell，无需额外迁移步骤。Windows、macOS 和 Linux 继续使用各自原有的安装包和配置目录。

## 破坏性变更与已知问题
