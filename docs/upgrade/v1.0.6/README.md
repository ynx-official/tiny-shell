# TinyShell v1.0.6

> 发布日期：2026-07-22

## 版本概述

重点增强终端右键操作与 SFTP 权限、延迟和对话框体验。

## 更新内容

- 新增终端右键菜单，支持复制、粘贴、查找和清空回滚缓存。
- 新增 SFTP 权限矩阵与递归应用选项。
- 在 SFTP 底栏加入连接延迟监测。
- 改进 SFTP 对话框焦点、显式操作按钮和工具栏默认可见性。

## 升级说明

该版本未记录配置格式破坏性变更，可直接覆盖安装。升级前建议关闭正在运行的 TinyShell 窗口，并保留现有配置备份。
