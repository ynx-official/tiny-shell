# TinyShell v1.0.4

> 发布日期：2026-07-21

## 版本概述

修复 Windows 安装包构建依赖问题，提高发布成功率。

## 更新内容

- 移除 Inno Setup 中缺失的语言依赖。
- 整理 v1.0.4 发布配置和版本元数据。

## 升级说明

该版本未记录配置格式破坏性变更，可直接覆盖安装。升级前建议关闭正在运行的 TinyShell 窗口，并保留现有配置备份。
