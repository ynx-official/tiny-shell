# TinyShell v1.0.61

> 发布日期：2026-07-23

## 版本概述

优化终端清理、资源展示、命令面板和 SSH 状态反馈，并统一品牌。

## 更新内容

- 终端清空可同时处理视口、回滚缓存、选区和滚动状态。
- 统一安装包、桌面入口、文档及界面中的 TinyShell 品牌。
- 重构 SFTP 底栏并增加系统负载侧栏。
- 压缩资源与进程布局，并增加可调整宽度的常用命令详情面板。

## 升级说明

该版本未记录配置格式破坏性变更，可直接覆盖安装。升级前建议关闭正在运行的 TinyShell 窗口，并保留现有配置备份。
