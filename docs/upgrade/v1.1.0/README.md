# TinyShell v1.1.0

> 发布日期：2026-07-23

## 版本概述

新增串口连接能力，并整理分支合并后的工程质量。

## 更新内容

- 支持串口连接。
- 提供虚拟 PTY 回退和自动换行转换。
- 对齐主开发分支代码并修复严格 Clippy 检查问题。
- 该标签来自独立发布线，发布日期早于部分 v1.0.x 标签。

## 升级说明

该版本未记录配置格式破坏性变更，可直接覆盖安装。升级前建议关闭正在运行的 TinyShell 窗口，并保留现有配置备份。
