# TinyShell v1.1.4

> 发布日期：2026-07-27

## 版本概述

重点增强配置同步、WebDAV 校验和跨平台发布流程。

## 更新内容

- 增加同步上传前置检查和操作引导。
- 改进 WebDAV 连接验证、配置处理和错误提示。
- 完善同步相关中英文文案及敏感配置处理。
- 优化跨平台 CI，并自动生成发布说明。

## 升级说明

该版本未记录配置格式破坏性变更，可直接覆盖安装。升级前建议关闭正在运行的 TinyShell 窗口，并保留现有配置备份。
