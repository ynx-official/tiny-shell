# TinyShell 版本更新记录

本目录采用“总览 + 分版本详情”的结构维护 TinyShell 发布历史。版本目录以 Git 标签为准；每份详情根据标签提交、最近祖先标签和代码差异整理。

> 注意：仓库没有 `v1.0.1` 标签，因此不创建对应目录。部分早期标签来自并行发布线，发布日期与版本号顺序并不完全一致；详情页按真实 Git 祖先关系提供比较链接。

## 文档维护规则

1. 新版本发布前创建 `upgrade/<version>/README.md`，目录名必须与 Git 标签一致。
2. 在本文件版本索引顶部加入新版本的发布日期和一句话摘要。
3. 在仓库根目录 `CHANGELOG.md` 顶部加入同版本的精简用户可见摘要和详情链接。
4. 详情应基于提交和代码差异归纳，不直接堆砌提交主题。
5. 用户可见日志只描述实际发生的功能、行为、兼容性和限制变化；没有变化的分类或“保持不变”占位说明不写入正文。
6. 无实际内容的分类不保留空标题；破坏性变更必须在升级说明中明确标注。
7. `Cargo.toml` 中的 `[package].version` 仍是应用当前版本的唯一代码来源。
8. 标签发布时，GitHub Actions 会校验版本号、发布日期、详情文档和索引，并从详情文档自动生成 GitHub Release Notes；校验失败时不会发布。
