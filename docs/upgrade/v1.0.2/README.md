# TinyShell v1.0.2

> 发布日期：2026-07-20

## 版本概述

完成 TinyShell 品牌迁移，并加入跨平台自动更新和快速连接管理。

## 更新内容

- 新增快速连接管理器及快速连接对话框。
- 新增 Linux、macOS、Windows 自动更新模块。
- 将应用结构体、资源、配置和环境变量统一更名为 TinyShell。
- 修复锁文件、图标命名、macOS 更新安装函数和 Windows 进程启动兼容问题。

## 升级说明

该版本未记录配置格式破坏性变更，可直接覆盖安装。升级前建议关闭正在运行的 TinyShell 窗口，并保留现有配置备份。
