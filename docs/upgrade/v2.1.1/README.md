## 版本概述

本次更新将设置子菜单改为独立内容页，点击 AI 中的「统计与审计」直接打开独立窗口；统一用量、操作、审批和留存设置的布局与详情展示，并将跨平台应用图标更新为黑白 TS 字母标识。按用户要求跳过测试，实际构建与发布结果单独记录。

## 改进与修复

### 设置导航

- 保留分类与子菜单层级，点击分类默认进入第一个内容子菜单。字体、终端行为、工作区、快捷键、在线更新及 AI 设置分别显示对应内容，独立保存窗口内滚动位置。
- 搜索支持分类、子菜单、设置项名称和说明，命中分类或子菜单时显示对应表单，命中设置项时筛选相应控件；空结果有明确反馈。
- AI 的「统计与审计」直接打开已有独立审计窗口，移除中间说明和二次打开按钮。
- 菜单切换取消未完成的快捷键录制；从 AI / MCP 发起重复设置跳转时重新定位目标分类并清空搜索。
- 保留可调整宽度的菜单、MCP / CLI 页面内页签，以及「关于」的应用信息和反馈入口。

### 统计与审计窗口

- 会话用量、操作审计、审批记录及留存设置使用统一页签、筛选、状态徽标和记录计数。用量显示数字概览，操作记录按列排列，审批有专门空状态。
- 宽窗口采用列表与右侧详情并排，窄窗口切到完整详情。参数、原始记录和长输出按需展开，详情保留请求、审批与结果时间线。
- 重置明细筛选保留当前会话范围；当前页无记录时禁用导出按钮，减少无效操作。
- 命令摘要采用已有用途说明，不额外请求模型或推断命令意图；SSH 控制和文件操作保留实际动作名称。

### 应用图标

- 更新运行时、Windows EXE / 安装器、macOS App Bundle 与 Linux 产物的图标资源，使用黑色底块和白色 TS 字母。
- Windows / Linux 保留透明外角和紧凑留白；macOS 使用不透明黑色满画布，由系统处理外部形状。同步 README 标识及导出脚本中的资源说明。

## 行为与界面变化

设置子菜单由页面内滚动锚点变为内容切换，向下滚动不会进入其他子菜单。审计窗口关闭后可回到原设置表单继续操作；查询菜单不会自动打开审计。

统计与审计使用当前深浅主题的颜色和紧凑间距。应用图标随新安装包更新，完全退出旧进程后重启才能使用新的嵌入资源；操作系统可能仍缓存旧图标。

## 配置与数据兼容性

本次没有改变配置格式、存储路径、同步协议、AI 密钥加密、本机会话历史或审计数据结构，没有数据迁移。仍使用 v4 配置同步；本次新增的页面选择、搜索和滚动状态仅保留在窗口内。

可回退至 v2.1.0 的程序版本，无需本次专属迁移；回退会恢复旧界面与旧图标。跨越 v2.0.0 或 v1.x 的同步兼容性限制仍按对应版本说明处理。

## 升级说明

可从 v2.1.0 直接覆盖安装。先完全退出旧进程，安装或解压替换后重新启动；无需额外修改设置或数据库。

Windows 提供 x86_64 安装包与便携包；Linux 提供 x86_64 AppImage 与压缩包；macOS Apple Silicon / Intel 各提供基础版和 RDP 版安装包及便携包。源码使用固定的 Rust 1.96.1 工具链和既有平台依赖。

## 破坏性变更与已知问题

没有新增破坏性配置变化。本版本按用户明确要求跳过测试与原生运行验收；构建成功也不能代替设置导航、表单草稿、审计交互或系统图标缓存的实机验证。真实 AI / SSH / WebDAV / S3 行为及 macOS / Linux 原生布局尚未在本轮验证。
