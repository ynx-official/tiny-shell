# TinyShell v1.1.5

> 发布日期：2026-07-27

## 版本概述

增加隐私密码验证与同步状态可见性。

## 更新内容

- 同步敏感数据前校验隐私密码是否缺失或不匹配。
- 增强同步设置和操作提示。
- 在 SFTP 底栏展示最近同步状态。
- 完善同步状态相关可见性配置。

## 升级说明

该版本未记录配置格式破坏性变更，可直接覆盖安装。升级前建议关闭正在运行的 TinyShell 窗口，并保留现有配置备份。
