## 版本概述

本次补丁修正 SFTP 文件修改时间固定按 UTC 显示的问题。连接成功后自动检测服务器时区；无法获取时使用本地时区，并在文件列表中标明当前规则。配置与文件时间戳无需迁移。

## 改进与修复

- 每次建立主 SFTP 连接后，在同一条已认证 SSH 连接的独立命令通道中检测一次时区；刷新、切换目录、上传下载和界面重绘不重复检测，重新连接后再检测。
- 文件时间按服务器的 IANA 时区和文件自身日期转换，正确处理冬夏时间；检测期间及不可用时按客户端本地时区显示。
- 文件列表表头上方增加中英文时区标识，区分服务器时区、检测中和本地回退；悬停提示说明检测周期与 UTC 偏移的含义。
- 限制探测超时和输出大小，连接关闭时取消任务，并忽略旧连接晚到的时区结果。
- 修正全目标检查中发现的既有 AI 界面测试临时字符串生命周期问题，以及两处等价的 Clippy 写法问题。缓存复用测试改用堆分配长文本验证共享地址，审批测试等待 Markdown 异步排版完成后再读取位置与点击，保留原测试断言和审批规则。

## 行为与界面变化

之前文件修改时间固定显示 UTC。升级后默认自动检测服务器时区，无需设置；例如显示“时区：服务器 · Asia/Shanghai (UTC+08:00)”。连接期间服务器修改时区，需要重新连接才能更新。文件时间使用对应日期的夏令时规则，标签中的 UTC 偏移表示当前日期的偏移。

## 配置与数据兼容性

不改变配置格式、存储位置、同步协议、密钥或文件原始时间戳。时区结果只按连接保存在内存中，不写入会话配置。可回退至 v2.1.2，无需数据迁移；回退后文件时间恢复按 UTC 显示。

## 升级说明

可从 v2.1.2 直接覆盖安装。完全退出旧版本，安装或替换程序后重新启动并连接服务器即可。

Windows、macOS、Linux 客户端使用相同的检测与转换规则，本地回退遵循客户端系统时区。Windows 提供安装包和便携包；Linux 提供 AppImage 和压缩包；macOS Apple Silicon、Intel 均提供基础版和 RDP 版。

## 破坏性变更与已知问题

没有新增破坏性配置或数据变化。服务器需要允许独立 SSH 命令通道；禁止 exec、命令缺失、超时或无法识别完整时区名称时回退本地，仍可浏览和传输文件。

Unix 服务器读取命令环境或系统时区配置；交互终端里临时设置的 TZ 不会同步。Windows 服务器探测需要 PowerShell 7 和支持 IANA 转换的 .NET/ICU 环境；旧环境使用本地回退。仅有当前偏移、模糊缩写、自定义 POSIX 规则或无时区名称的系统不会用于猜测。

真实远程服务器、原生界面的窄宽度与深浅主题仍需手动验收；自动测试和构建不能替代这些验证。

## 线上更新说明

TinyShell v2.1.3

修正 SFTP 文件修改时间固定按 UTC 显示的问题。现在默认自动检测服务器时区，获取不到时使用电脑本地时区。

时区检测只在每次建立连接时执行一次。刷新、切换目录、上传和下载不会重复检测；服务器时区变更后重新连接即可更新。

文件列表显示当前使用的时区，并区分检测中、服务器时区和本地回退。文件时间按各自日期应用夏令时规则。

检测失败或超时不会阻止目录浏览和文件传输。受限账号及不支持时区查询的服务器自动使用本地时区。

可从 v2.1.2 直接覆盖安装，退出旧版本后重新启动即可。配置、连接记录、密钥、同步数据和文件原始时间戳无需迁移。

## 重点手动验收

1. 连接已知时区的 SSH 服务器，打开 SFTP，确认标签及文件时间与服务器一致。
2. 连续刷新、切换目录及上传下载，确认没有新时区探测命令，文件操作保持正常。
3. 禁止 exec 或无法识别时区时，确认显示本地回退且目录仍可用。
4. 查看纽约等服务器的冬季和夏季文件，确认按各自日期转换。
5. 快速断开重连及同时使用不同时区连接，确认结果互不覆盖。
6. 切换中英文、深浅主题并缩窄面板，检查时区文字和悬停提示。
