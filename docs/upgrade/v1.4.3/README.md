# TinyShell v1.4.3

> 发布日期：2026-03-14

## 版本概述

本版本为 SFTP 单文件传输增加断点续传能力。上传和下载过程中会使用稳定的 `.part` 临时文件保存已完成部分，连接中断或程序重启后，用户重新连接对应会话即可手动继续任务，避免重新传输已经完成的数据。

## 新功能

- SFTP 单文件下载支持从本地 `.part` 文件大小对应的远端偏移继续读取。
- SFTP 单文件上传支持从远端 `.part` 文件大小对应的本地偏移继续写入。
- 传输记录持久化稳定的 `transfer_id`、`session_id`、源文件大小与修改时间、临时路径和恢复状态。
- 传输窗口提供继续、重新开始以及删除并清理临时文件操作。

## 改进与修复

- 传输完成前不覆盖正式目标文件，完成后才将临时文件替换为最终文件。
- 连接中断、暂停、取消和可恢复失败保留实际偏移进度，并通过节流方式持久化，降低高频完整配置保存。
- 恢复前校验源文件大小和修改时间；临时文件大于源文件、源文件发生变化或目标冲突时拒绝盲目拼接。
- 旧版传输记录保持可读取；缺少恢复元数据的旧记录不会被伪装成可继续任务。
- 新增中英文恢复状态、源文件变化、临时文件无效和会话未连接等界面文案。

## 行为与界面变化

- 传输中断后，任务会显示为可恢复状态，而不是直接丢失进度。
- 程序重启后，任务记录仍会显示在传输窗口；用户需要先重新连接原 SSH 会话，再点击继续。
- 删除传输记录时会尝试清理对应的本地或远端 `.part` 文件。
- 首版仅支持单文件上传和下载，不支持文件夹传输、批量任务整体恢复或打包下载断点续传。

## 配置与数据兼容性

- 现有配置和会话数据可以直接读取；新增传输字段使用兼容默认值。
- 旧版运行中或暂停的传输记录会根据是否具备完整恢复信息转换为恢复候选或旧式不可恢复记录。
- `.part` 文件是新增的临时产物，不会覆盖已有正式目标文件；删除记录时会尝试清理它们。

## 升级说明

Windows、macOS 和 Linux 用户可以直接覆盖安装。升级后如需继续旧任务，请重新连接保存记录对应的 SSH 会话，再从传输窗口手动恢复。升级前如存在重要未完成传输，建议保留本地 `.part` 文件和配置备份。

## 破坏性变更与已知问题

- 不支持文件夹、批量任务整体和打包下载的断点续传。
- 首版使用源文件大小、修改时间和最终长度进行校验，不提供全文件哈希或分块哈希校验。
- 不会自动后台重连、自动重试或静默发起认证。
- 目标文件冲突、源文件变化或临时文件异常时，需要选择重新开始或取消，不能直接强制拼接。
