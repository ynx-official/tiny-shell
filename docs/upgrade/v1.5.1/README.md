# TinyShell v1.5.1

> 发布日期：2026-08-14

## 版本概述

本版本将 v3 配置同步进一步接入应用运行流程，新增统一的 WebDAV 自动对账协调器、baseline 三方合并和冲突处理体验。同步期间发生的本地修改、远端条件写入冲突和删除状态会被明确保留，减少多设备使用时的覆盖和状态丢失风险。

## 新功能

- WebDAV 自动对账统一由一个协调器处理，支持应用启动、本地配置保存后的防抖、窗口激活节流、周期检查和失败退避重试。
- 使用加密 baseline 对本地、上次成功同步状态和远端 payload 执行三方比较。
- 设置页显示冲突实体和安全标签，支持保留本地、使用远端、复制为新连接以及批量应用剩余冲突策略。
- v3 payload 补全 sessions、managed keys、连接分组和快捷命令的删除墓碑传播。
- 对内容等价的同步结果跳过无意义的远端 PUT，同时仍保存新的 ETag 和 baseline。

## 改进与修复

- 同步中的本地保存会记录待处理代次，旧同步成功不会清除新产生的本地变化。
- 上传、下载、合并、配置持久化和 baseline 持久化任一步失败，都不会被记录为完整同步成功。
- ETag 条件冲突会重新拉取并合并，不会无条件覆盖其他设备的新内容。
- 冲突上下文在本地配置再次变化后失效并重新对账，避免使用过期决策覆盖当前配置。
- 完善同步设置、冲突窗口、启动流程、窗口激活和失败退避的状态提示及中英文文案。

## 行为与界面变化

- WebDAV 同步不再只依赖手动触发；满足自动对账条件时会在后台检查远端变化。
- 检测到同一实体在本地和远端同时发生不同修改时，应用会显示冲突并暂停上传，等待用户选择策略。
- 本地和远端内容等价时不会产生无意义的上传，但仍会更新同步状态和 baseline。

## 配置与数据兼容性

- 本地应用配置格式保持兼容。
- v3 同步协议、加密 baseline 和同步目标隔离方式沿用 `v1.5.0`，不需要重新迁移已建立的 v3 baseline。
- v1/v2 同步对象仍不自动迁移；请继续遵循 `v1.5.0` 的升级说明重新建立 v3 同步目标。

## 升级说明

Windows、macOS 和 Linux 用户可以直接覆盖安装。建议确保所有使用同一同步目标的设备都升级到支持 v3 的版本；首次启用或恢复同步时，请在冲突列表中确认本地和远端版本后再提交解决结果。

## 破坏性变更与已知问题

- 未改变 `v1.5.0` 的 v3 同步协议格式，但旧 v1/v2 同步对象仍不受支持。
- 连接分组实体 ID 当前由分组名称稳定派生，重命名仍表现为删除旧分组并新增新分组。
- 尚未定义 tombstone 自动清理和多设备确认水位。
- 未执行真实 WebDAV/S3、双设备离线编辑、macOS/Linux 构建及桌面 UI 手工验收。
- 按用户要求跳过测试，因此本版本不声明测试套件通过。
