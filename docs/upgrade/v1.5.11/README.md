# TinyShell v1.5.11

> 发布日期：2026-08-19

## 版本概述

本版本集中改善连接目标选择、SFTP 文本编辑和文件权限管理，并让工作区布局在应用重启后恢复。连接分组树、终端标签栏、SFTP 面板和监控界面的布局也得到统一，减少窄窗口和长内容下的溢出问题。

## 新功能

- 新增可展开、可滚动的连接分组树选择器，支持在连接编辑、连接操作和设置页中选择分组目标。
- SFTP 文本编辑器支持选择文本编码，并在读取或保存时使用对应编码处理文件内容。
- SFTP 文件列表和编辑流程新增权限展示与修改能力，权限输入会进行格式校验。
- WebDAV 自动对账接入应用启动、本地配置保存和窗口状态变化等触发事件，并复用既有防抖、代次和退避机制。

## 改进与修复

- 工作区标签、分屏和面板布局随偏好持久化，重新启动后恢复上次布局。
- 优化终端标签栏选中态和指示器、连接树行高与缩进、SFTP 面板以及监控面板的对齐和溢出处理。
- 统一连接目标选择器的树形展开、滚动和行高，避免长分组列表遮挡后续内容。
- 完善 SFTP 编码失败、权限操作失败和连接状态异常时的中英文反馈。

## 行为与界面变化

- 连接编辑和连接操作中的分组选择由平面列表改为可展开树形选择。
- SFTP 编辑文本时可选择目标编码；未指定编码时继续使用项目默认行为。
- 工作区布局会在配置持久化后保存，应用重启后自动恢复。
- 终端和 SFTP 长文本、长主机名及多级分组会在可用空间不足时省略显示，不再挤压操作区域。

## 配置与数据兼容性

- 现有配置、会话、同步、托管密钥和传输记录保持兼容，无需迁移。
- 新增工作区布局、文本编码和权限相关字段使用兼容默认值。
- SFTP 权限修改直接作用于远端文件，执行前应确认目标路径和权限值。

## 升级说明

Windows、macOS 和 Linux 用户可以直接覆盖安装。升级后首次打开 SFTP 编辑器时，可按文件实际编码选择编码；修改远端权限前请确认当前用户具备对应服务器权限。

## 破坏性变更与已知问题

- 无配置、会话或同步协议破坏性变更。
- 文本文件编码依赖服务器文件内容和用户选择，自动检测无法保证对所有混合编码文件正确识别。
- SFTP 权限能力受远端操作系统、文件系统和当前账户权限限制。
- 按用户要求跳过测试、静态检查和本地 release 构建，未执行跨平台手工验收。
