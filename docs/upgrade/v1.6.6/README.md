# TinyShell v1.6.6

> 发布日期：2026-09-30

## 版本概述

本版本重点优化快速连接弹窗，使连接列表能够根据窗口空间自适应展开，并以更清晰的三列结构展示连接名称、地址和用户信息。

## 改进与修复

- 快速连接弹窗改为按窗口宽度自适应，并在可用空间内动态计算列表高度。
- 统一分组和连接行高，优化多级分组、折叠和滚动行为。
- 将连接信息拆分为名称、地址 / 端口和用户列，IPv6 地址使用方括号正确显示端口。
- 增加完整信息悬停提示，优化搜索提示、本地化文案和小窗口边界处理。

## 行为与界面变化

快速连接列表不再固定为窄面板；窗口空间足够时会展示更多内容，空间不足时保留搜索、列标题和底栏并仅滚动列表区域。选中项在悬停时保持选中高亮。

## 配置与数据兼容性

连接配置、会话数据、同步协议和工作区数据格式保持兼容，无需迁移。

## 升级说明

可直接覆盖安装。升级后重新打开快速连接弹窗即可使用新的布局。

## 破坏性变更与已知问题
