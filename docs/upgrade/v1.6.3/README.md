# TinyShell v1.6.3

> 发布日期：2026-09-07

## 版本概述

本版本集中补齐连接管理、会话编辑、SSH 私钥导入和应用更新能力，并扩展终端高亮规则，提升日常连接配置与终端使用体验。

## 新功能

- 新增快速连接管理窗口与会话编辑流程。
- SSH 私钥导入支持直接输入文本。
- 新增应用内更新能力。
- 扩展内置终端高亮规则。

## 改进与修复

- 统一确认框和更新器对话框的居中布局。
- 恢复跨平台 CI 检查配置。

## 行为与界面变化

连接管理器支持更直接的快速连接和会话编辑；私钥导入增加文本输入路径；应用可在更新器流程中处理更新。

## 配置与数据兼容性

既有配置、会话、同步和工作区数据保持兼容。本版本新增配置字段按应用逻辑处理，无需手动迁移。

## 升级说明

可直接覆盖安装。建议在更新前保留现有配置备份。

## 破坏性变更与已知问题

未发现破坏性变更。由于本次按要求跳过本地测试、静态检查和 release 构建，跨平台产物仍需由标签流水线验证。

## 验证结果

- 按发布要求跳过 `cargo fmt`、Clippy、测试和本地 release 构建。
- 已完成版本号、`Cargo.lock`、变更日志、升级总览和版本详情的一致性检查。
