# TinyShell v1.5.14

> 发布日期：2026-08-21

## 版本概述

本版本继续完善启动窗口体验，在 macOS 上补齐原生窗口位置动画和目标显示器可见区域约束，并调整 Windows、macOS 共用的启动展开时长与缓动曲线，使紧凑 loading 窗口过渡到主工作区时更加平缓。配置、会话、同步和工作区数据格式保持兼容。

## 改进与修复

- macOS 启动窗口以保存的目标窗口中心为基准，不再固定沿用目标窗口左上角。
- 当保存的窗口位置部分位于屏幕外时，将紧凑启动窗口约束在目标显示器可见区域内。
- macOS 通过 AppKit 原生窗口句柄同步移动启动窗口位置，避免展开过程中仅改变尺寸造成的位置跳变。
- 将启动展开时长由 220 毫秒调整为 520 毫秒，并采用更平缓的三次缓出曲线。

## 行为与界面变化

Windows 和 macOS 启动时，紧凑 loading 窗口会从保存的工作区中心位置平滑移动并扩展到目标边界。Linux 继续从保存位置使用原有跨平台回退动画。

## 配置与数据兼容性

配置、会话、同步、传输和工作区数据格式没有变化，无需迁移。macOS 构建新增原生 Cocoa 与 Objective-C 桥接依赖，不影响用户配置。

## 升级说明

可直接覆盖安装，无需备份或迁移。首次启动即可看到新的启动窗口动画。

## 破坏性变更与已知问题

没有已知破坏性变更。原生窗口定位仍可能受多显示器缩放、系统窗口管理器以及显示器布局变化影响；无法取得原生窗口句柄时会记录一次警告并继续启动。
