# TinyShell v1.6.1

> 发布日期：2026-08-23

## 版本概述

本版本修复 macOS RDP 画面渲染链路，并将 macOS 发布产物拆分为基础版和 RDP 版，用户可以按需选择更小的基础安装包，或选择内置 FreeRDP 的 RDP 安装包。

## 新功能

- macOS 提供基础版和 RDP 版两套独立发布产物。
- 两个版本分别提供 `.pkg` 安装包和 `.zip` 便携包。
- 基础版使用无 FreeRDP 后端构建，RDP 版使用 FreeRDP 3 并嵌入运行时动态库。

## 改进与修复

- 修复 macOS RDP 帧数据进入 GPUI 纹理渲染链路的问题，改善远程桌面画面显示。
- 更新 macOS 打包脚本，支持按版本构建和打包基础版、RDP 版。
- 更新在线更新器和更新清单，避免两个 macOS 版本误选对方的升级包。

## 行为与界面变化

macOS 发布文件名中的 `-rdp-` 表示 RDP 版；不带该标识的是基础版。两种版本均安装为 `TinyShell.app`，同一台 Mac 上建议只保留正在使用的版本。

## 配置与数据兼容性

既有配置、会话、同步和工作区数据保持兼容，无需迁移。

## 升级说明

不需要 RDP 的用户请选择不带 `-rdp-` 的基础版；需要远程桌面连接的用户请选择带 `-rdp-` 的安装包。两种版本都可以覆盖安装到 `/Applications/TinyShell.app`。

## 破坏性变更与已知问题

没有已知破坏性变更。macOS 基础版不包含 FreeRDP 原生后端，使用基础版时 RDP 功能不可用。

## 验证结果

- 按发布要求跳过本地测试、格式检查、Clippy 和 release 构建。
- 正式标签流水线负责 macOS、Windows、Linux 构建、打包和发布验证。
