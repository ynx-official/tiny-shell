# TinyShell v1.1.6

> 发布日期：2026-07-27

## 版本概述

将快速连接升级为树形连接管理器，并加入安全的归档与回收站能力。

## 更新内容

- 支持连接和分组搜索、排序、展开折叠、右键操作和移动。
- 支持软删除、回收站恢复及同步墓碑。
- 支持连接信息复制和已删除项目管理。
- 支持带密码加密的 TinyShell JSON 导入导出，敏感字段不明文保存。

## 升级说明

该版本未记录配置格式破坏性变更，可直接覆盖安装。升级前建议关闭正在运行的 TinyShell 窗口，并保留现有配置备份。
