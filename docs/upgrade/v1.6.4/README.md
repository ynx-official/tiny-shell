# TinyShell v1.6.4

> 发布日期：2026-09-30

## 版本概述

本版本统一确认弹窗和会话相关操作的交互结构，简化终端工作区中的会话管理，并进一步优化快速连接弹窗的布局与操作流程。

## 改进与修复

- 新增统一确认弹窗组件，统一删除、SFTP、同步、更新等场景的确认交互。
- 简化终端工作区和会话管理相关的状态与对话框处理。
- 优化快速连接弹窗的布局、信息展示和操作反馈。

## 行为与界面变化

涉及确认操作的窗口使用统一的标题、说明和操作按钮布局；快速连接弹窗的连接选择与编辑流程更加紧凑。

## 配置与数据兼容性

既有配置、会话、同步和工作区数据保持兼容，无需手动迁移。

## 升级说明

可直接覆盖安装。升级后重新打开应用即可使用新的交互布局。

## 破坏性变更与已知问题

未发现破坏性变更。由于本次按要求跳过本地测试、静态检查和 release 构建，跨平台产物仍需由标签流水线验证。

## 验证结果

- 按发布要求跳过 `cargo fmt`、Clippy、测试和本地 release 构建。
- 已完成版本号、`Cargo.lock`、变更日志、升级总览和版本详情的一致性更新。
