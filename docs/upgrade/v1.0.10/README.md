# TinyShell v1.0.10

> 发布日期：2026-07-24

## 版本概述

加固 macOS 自动更新的下载和应用包替换安全性。

## 更新内容

- 增强 macOS App Bundle 原子替换流程。
- 限制更新包下载大小。
- 使用更安全的临时目录与路径处理。
- 降低异常更新包和残留文件造成的安装风险。

## 升级说明

该版本未记录配置格式破坏性变更，可直接覆盖安装。升级前建议关闭正在运行的 TinyShell 窗口，并保留现有配置备份。
