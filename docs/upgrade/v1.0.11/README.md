# TinyShell v1.0.11

> 发布日期：2026-07-24

## 版本概述

修复在线更新版本比较逻辑。

## 更新内容

- 将版本判断改为数值化语义比较。
- 避免 `1.0.10` 与 `1.0.9` 等版本被按字符串顺序误判。
- 同步应用版本和锁文件。

## 升级说明

该版本未记录配置格式破坏性变更，可直接覆盖安装。升级前建议关闭正在运行的 TinyShell 窗口，并保留现有配置备份。
