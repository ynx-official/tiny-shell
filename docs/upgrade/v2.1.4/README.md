## 版本概述

本次补丁将 SFTP 时区信息改为按需显示，移除文件表头上方的常驻时区行。默认隐藏，在底部工具栏右键菜单中勾选“时区”后显示，并保存用户选择。服务器时区检测和文件时间转换沿用 v2.1.3 的规则。

## 改进与修复

- 移除文件列表表头上方的时区行，恢复左右表头对齐并释放文件列表高度。
- 底部工具栏右键菜单增加“时区”选项，默认不勾选；勾选后在底部显示当前活动 SFTP 连接的时区，取消后立即隐藏。
- 显示偏好沿用现有保存流程，重启后保留。旧配置没有该字段时默认隐藏，既有底栏显示选项保持原选择。
- 底部标签区分服务器时区、检测中和本地回退；宽度不足时截断，悬停可查看完整说明。中英文文案同步更新。

## 行为与界面变化

在普通工作区底部工具栏上点击右键，勾选“时区”即可显示。切换 SSH 标签时显示对应连接的时区，没有活动 SFTP 连接时隐藏。Clean 模式沿用隐藏整个底栏的规则，退出后恢复已保存的显示选择。

显示开关只控制标签可见性，不改变文件修改时间的转换方式，也不触发新的探测。时区仍只在每次建立 SFTP 连接时自动检测一次，失败时使用客户端本地时区；刷新、切换目录和上传下载不重新检测。

## 配置与数据兼容性

在已有 sftp_footer_visibility 中增加可选的 timezone 布尔字段，默认 false。旧配置自动使用默认值，无需迁移；配置路径、连接数据、密钥、同步协议及文件原始时间戳不变。

可回退到 v2.1.3，无需专属数据迁移；回退后恢复表头上方常驻时区行。旧版本保存配置可能丢弃不认识的显示偏好字段，再升级时可重新勾选。

## 升级说明

可从 v2.1.3 直接覆盖安装。完全退出旧进程，安装或替换程序后重新启动；需要显示时区时，在底部工具栏右键菜单中启用。

Windows、macOS、Linux 使用相同的显示规则。Windows 提供 x86_64 安装包和便携包；Linux 提供 x86_64 AppImage 和压缩包；macOS Apple Silicon、Intel 均提供基础版与 RDP 版安装包和便携包。

## 破坏性变更与已知问题

没有新增破坏性配置或数据变化。Clean 模式隐藏底部工具栏，需要退出该模式才能使用底栏时区选项。服务器检测的环境限制沿用 v2.1.3；不可识别或禁止查询时继续回退本地。

本次原生界面的勾选、重启恢复、窄窗口和深浅主题仍需手动验收，自动测试与构建不能替代这些交互验证。

## 线上更新说明

TinyShell v2.1.4

SFTP 时区信息改为按需显示，默认隐藏，不再占用文件表头上方的一行。

在底部工具栏上点击右键，勾选“时区”即可查看当前连接使用的时区；取消勾选立即隐藏，选择会在重启后保留。

连接时自动检测一次服务器时区、获取失败时使用电脑本地时区的规则保持不变。显示开关不会重新探测，也不会改变文件时间。

可从 v2.1.3 直接覆盖安装，退出旧版本后重新启动即可。连接记录、密钥和文件数据无需迁移。

## 重点手动验收

1. 升级后打开 SSH/SFTP，确认默认没有时区标签，左右文件表头对齐，文件修改时间仍正确。
2. 底部工具栏右键勾选“时区”，确认底部立即显示；取消后立即隐藏。分别保存勾选和取消状态后重启，确认选择保留。
3. 切换不同时区的 SSH 连接及本地终端，确认标签跟随当前连接，无 SFTP 时隐藏；刷新和切换显示不新增探测命令。
4. 缩窄窗口、切换中英文和深浅主题，确认文字截断与悬停提示正常，传输、延迟和面板收起入口可用。
