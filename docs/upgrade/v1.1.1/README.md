# TinyShell v1.1.1

> 发布日期：2026-07-25

## 版本概述

汇总更新器安全、独立设置窗口、界面动画和多窗口交互改进。

## 更新内容

- 加固 macOS 应用包替换、临时路径和下载大小限制。
- 修复更新器安装旧二进制及版本数字比较问题。
- 整合独立设置窗口、标签拖拽和多窗口状态处理。
- 整合工作区、面板、标签和状态指示动画。

## 升级说明

该版本未记录配置格式破坏性变更，可直接覆盖安装。升级前建议关闭正在运行的 TinyShell 窗口，并保留现有配置备份。
