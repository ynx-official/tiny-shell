# TinyShell v1.6.0

> 发布日期：2026-08-21

## 版本概述

本版本新增终端高亮规则配置能力，提供可持久化的设置界面和更完整的终端渲染支持；同时优化搜索、会话操作和设置交互，并更新应用图标及 Windows 构建资源追踪。

## 新功能

- 新增终端高亮规则设置，可配置匹配规则、前景色、背景色和字体样式。
- 新增高亮规则配置存储、默认规则处理和会话级应用能力。
- 设置窗口新增终端高亮配置入口，支持规则编辑和相关交互反馈。

## 改进与修复

- 优化终端高亮解析与渲染链路，改善规则处理和多行终端内容的显示一致性。
- 优化终端搜索、会话操作、终端设置和中英文文案。
- 更新应用图标资源，减少部分平台图标体积。
- 修复 Windows 构建脚本未可靠追踪应用图标变化的问题，图标更新会触发原生资源重建。

## 行为与界面变化

终端设置中新增高亮规则管理界面。保存规则后，后续终端渲染会按当前配置应用匹配样式；未配置自定义规则时继续使用默认行为。

## 配置与数据兼容性

既有配置、会话、同步和工作区数据保持兼容。新增高亮字段为可选配置，旧配置读取时使用默认规则，无需手动迁移。

## 升级说明

可直接覆盖安装。升级后可在终端设置中按需配置高亮规则；不使用该功能时无需额外操作。

## 破坏性变更与已知问题

没有已知破坏性变更。高亮规则效果受终端内容格式和主题颜色对比度影响，复杂匹配规则可能增加渲染开销。
