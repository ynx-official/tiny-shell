# TinyShell v1.1.7

> 发布日期：2026-07-28

## 版本概述

将连接管理操作迁移到独立窗口，并增强多窗口编辑的一致性和冲突保护。

## 更新内容

- 快速连接、分组操作、连接移动和归档导入导出使用独立系统窗口。
- SSH 新建与编辑支持多个隔离草稿窗口。
- 保存使用原子写入和乐观并发冲突检测。
- 优化编辑窗口布局，支持 Esc 关闭，并在连接成功后自动关闭快速连接窗口。

## 升级说明

该版本未记录配置格式破坏性变更，可直接覆盖安装。升级前建议关闭正在运行的 TinyShell 窗口，并保留现有配置备份。
