# TinyShell v1.0.62

> 发布日期：2026-07-23

## 版本概述

修复自动更新可能安装旧二进制文件的问题。

## 更新内容

- 安装前校验更新产物版本。
- 阻止残留或过期更新文件被再次安装。
- 同步发布版本和锁文件。

## 升级说明

该版本未记录配置格式破坏性变更，可直接覆盖安装。升级前建议关闭正在运行的 TinyShell 窗口，并保留现有配置备份。
