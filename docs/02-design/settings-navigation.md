## 已确认范围

用户于 2026-10-13 确认：设置中的各个子菜单显示独立内容；AI 下的「统计与审计」点击后直接打开已有独立页面。

变更原因：原设置组件点击子菜单只滚动到同一长页面的分组，各分组内容连续显示；审计入口还需先进入说明区域，再点击打开按钮。

## 导航行为

- 保留现有分类和子菜单层级。点击分类默认进入第一个内容子菜单；右侧只显示当前子菜单的设置内容。
- 每个内容子菜单独立滚动并保留窗口内的滚动位置。菜单宽度仍可拖动调整。
- 「关于」的应用信息及反馈入口作为该分类的共同上下文，与版本信息一起显示；MCP / CLI 保留现有页面内页签。
- AI →「统计与审计」直接调用已有审计窗口入口。设置窗口保留当前表单，关闭审计后可继续操作，无需中间说明页面。
- 搜索匹配分类、子菜单、设置项名称和说明，不区分大小写。命中分类或子菜单时展示对应表单；只命中设置项时筛选这些设置项。自定义表单按其分类或子菜单名称查找。
- 搜索未命中时显示「无结果」。只命中审计入口时保留可点击菜单，查询和渲染本身不自动打开审计窗口。清空搜索后恢复查询前的内容选择。
- 切换菜单时取消未完成的快捷键录制，避免隐藏的快捷键表单继续截获输入。
- AI / MCP 从其他页面发起设置跳转时，定位到目标分类并清空搜索；重复请求同一分类仍可定位。

## 实现边界

`src/app/settings/navigation.rs` 管理窗口内选择、搜索、菜单、独立滚动和打开操作；`src/app/settings/page.rs` 描述分类、内容分组及现有自定义表单。各设置模块继续维护原有控件、业务事件和配置保存逻辑。

沿用项目 `awesome-design-md / sentry` 风格、GPUI 组件、现有主题及 8px 间距。配置格式、存储、同步、审计权限与数据留存规则不变，不需要迁移。

## 手动验收

1. 设置 → 终端 → 字体：向下滚动，确认不会出现「终端行为」内容；切到「终端行为」再返回「字体」，确认内容及各自滚动位置正确。
2. 逐一切换工作区、快捷键、在线更新和 AI 的子菜单：右侧标题、选中状态和内容对应；分类入口打开第一个内容子菜单；「关于」仍有应用信息和反馈入口。
3. AI → 统计与审计：一次点击打开已有独立窗口；确认查询、页签及关闭操作正常，原设置窗口仍可继续使用。审计服务不可用时应显示既有错误反馈。
4. 在 AI 表单中输入尚未保存的内容，切到执行预算再返回：确认草稿仍在；修改普通设置并关闭后重新打开，确认保存行为正常。
5. 搜索「字体」「预算」「统计与审计」及不存在的文字；确认结果对应、搜索不会自行打开审计、点击审计入口可打开窗口。清空搜索后不出现错位内容。
6. 开始录制快捷键后切换子菜单，确认普通输入不再被录制；从 AI 的设置入口与权限入口重复跳转，确认每次都定位到 AI 或 MCP / CLI。
7. 将设置窗口缩到最小尺寸并调整菜单宽度，检查内容滚动、长文字、按钮和 MCP 内部页签没有遮挡或重叠。
