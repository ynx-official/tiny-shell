# SSH 私钥导入

> 状态：Review  
> 最后更新：2026-09-07  
> 关联文档：[文档索引](../README.md)

导入弹窗支持“选择文件”和“填写文本”两种方式，默认选择文件。文本输入支持完整的 OpenSSH 私钥，包括 BEGIN / END 行；继续兼容现有解析器支持的其他私钥格式。加密私钥需填写正确口令。

两种来源使用同一解析器校验算法和 SHA256 指纹，重复密钥不能保存。空文本、仅有格式头、损坏私钥和公钥不能作为私钥导入。名称沿用既有规则：留空时文件方式使用文件名，文本方式使用 imported-key。

切换来源会清空之前的文件和文本内容，取消尚未完成的文件选择或读取；备注与口令保留。关闭弹窗或导入成功后清空文本与口令。文本内容不会作为日志输出。

修复文件读取结束后校验状态仍停留在“正在校验”的问题。持久化继续使用已有 ManagedKey 和配置保存流程，不改变配置格式或同步协议。
