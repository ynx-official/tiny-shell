# 终端内容高亮方案

> 状态：Approved  
> 最后更新：2026-08-27  
> 关联实现：`src/session/highlight_rules.rs`、`src/terminal/highlight.rs`、`src/app/settings/highlighting.rs`

## 目标与边界

本功能提升终端输出中高信号内容的识别覆盖率，不提供终端主题，也不改变既有高亮颜色。ANSI 样式仍是基础层；搜索、选区和全屏 TUI 的原生视觉语义优先于持久高亮。

## 规则模型

- 规则按 Core、Network、Web、Development、Git、Containers、Database、Security 和 Custom 分类。
- Core、Network、Web、Development 默认启用；专业规则包按需开启，降低误报。
- 规则包含分类、捕获组、语义实体和作用域元数据。
- 匹配优先级为会话规则、最深层分组规则、全局规则；同一层级按列表顺序决定覆盖关系。
- 分组作用域同时作用于其子分组，会话作用域只匹配稳定的会话 ID。

## 内容解析

- JSON 与 logfmt：解析键值字段并保留值的字节范围。
- 堆栈：识别 JavaScript/Java 风格 `at`、Python `File ..., line ...`、异常原因和 Go goroutine 帧。
- 文件位置：识别 Windows、Unix、相对路径及 `line:column` 坐标。
- 捕获组允许规则只高亮语义值，例如 `"level":"error"` 中的 `error`。
- 预览解释器显示命中规则、实际文本、分类和可用语义动作。

## 语义动作

按住 Ctrl（macOS 为 Command）点击实体时：

| 实体 | 本地终端 | 远程终端 |
|---|---|---|
| URL | 默认浏览器打开 | 默认浏览器打开 |
| 邮箱 | 默认邮件应用打开 | 默认邮件应用打开 |
| 文件路径 | 系统默认应用打开 | 复制路径 |
| IP、MAC、UUID | 复制 | 复制 |

远程路径不会在本机误打开。实体悬停与点击独立于“内容高亮”总开关。

## 配置兼容与交换格式

- 内置规则包使用独立版本号升级；未修改的旧默认规则会升级，用户编辑过的规则行为保持不变。
- 旧配置缺少分类、作用域或语义字段时按兼容默认值读取，并为已知内置 ID 补齐元数据。
- 导入导出使用带 `format_version`、`builtin_pack_version`、启用规则包和完整规则列表的 JSON 文件。
- 导入会拒绝不支持的格式版本、空规则 ID 和重复规则 ID。

## 性能与限制

- 正则表达式限制为 512 个字符、1 MiB 编译空间；每条规则每行最多处理 512 次匹配，启用规则最多 128 条。
- 终端只重新匹配受 damage 影响的逻辑行；规则、作用域或规则包变化通过指纹使缓存失效。
- 2026-08-27 在 Windows debug 测试构建中，28 条规则开启时 10,000 次增量渲染耗时约 3.02 秒。该数据用于回归比较，不作为跨机器硬性门槛。

## 验收要点

- 普通词 `backup`、`token`、`thread`、`payload` 不因短词子串产生误报。
- JSON/logfmt 只可通过捕获组高亮目标值。
- Git 冲突标记、容器故障、数据库错误和安全通告由对应可选规则包控制。
- 本地与远程文件路径执行不同动作。
- 旧配置、用户自定义规则、规则顺序和样式保持兼容。
