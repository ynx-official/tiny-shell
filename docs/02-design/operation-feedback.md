# 通用操作反馈

> 状态：Review
> 最后更新：2026-10-22
> 关联：[统一确认弹窗](confirmation-dialogs.md)、[AI 厂商设置](ai-provider-settings.md)

## 已确认范围

用户确认统一成功、失败、警告浮动提示，并补齐缺少反馈的操作。复用 `src/feedback.rs` 和 gpui-component 的通知层；不新增通知中心、系统通知权限或配置格式。

通知展示与复制逻辑集中在 `src/feedback/presentation.rs`，由原入口重导出；工作区归属路由仍由 `src/feedback.rs` 负责。独立 AI 工具步骤预览复用同一展示模块并挂载通知层，避免引入整个应用的窗口状态依赖。

## 显示与文案

沿用项目 `awesome-design-md / sentry` 与原生组件，主题提供成功、危险、警告和信息颜色。每条消息由语义图标、状态标题和具体结果组成，正文保留具体错误或操作对象，不能只显示“失败”。

| 类型 | 中文标题 | 使用边界 |
| --- | --- | --- |
| Success | 操作成功 | 请求实际完成，例如已保存、已删除、已复制到剪贴板 |
| Error | 操作失败 | 写入、网络或实际执行失败；保留可理解的原因 |
| Warning | 请注意 | 输入不合法、缺少模型、正在忙等可修正前提 |
| Info | 提示 | 中性结果或已存在状态 |

所有新增文案同时维护中英文。通知沿用组件当前位置、关闭按钮及默认五秒自动隐藏；不中断键盘焦点。连接中、传输进度、自动同步状态仍由原位置显示，不将每次状态更新转换为通知。表单内错误继续保留，便于修改。

## 接入与完成时机

- 所有现有 `Feedback` 调用统一增加状态标题，沿用业务正文。
- AI 厂商保存/删除、清除 Key、测试连接、刷新模型，以及预算、通知偏好、续聊偏好保存，使用独立 `OperationReceipt`。返回回执仅表示已受理；回执收到实际结果后显示提示。完成结果不依赖可被后续操作覆盖的 `Snapshot.notice`。
- AI 输入或前置校验失败立即显示警告；磁盘和网络失败显示错误。每个回执最多消费一次，不在 render 中重复触发提示。原窗口关闭后不将结果投递到其他窗口，后台已受理操作继续完成。
- 代理保存等待配置仓库的实际写入结果；排队或写入失败使用现有“配置保存失败”文案。
- AI 消息、代码块、工具步骤、审计引用/详情、SFTP 路径的主动复制补充成功反馈。复制提示只显示通用文本，不重复显示复制内容。终端自动选区复制和远程剪贴板同步保持静默。
- 审计窗口补挂通知层，使复制提示有渲染入口。
- SFTP 新建文件/文件夹、重命名、权限修改、普通/快速删除使用 `SftpOperationFinished` 显式结果事件，按原会话路由到所属工作区，同时更新原状态栏。不根据翻译后的字符串判断成功或失败；进度继续使用 `SftpStatus`。
- SFTP 名称/权限校验、常用命令名称/内容/分类校验失败补充警告，保留原对话框和草稿；连接分组名称为空时明确提示“请输入分组名称”。

SFTP 上传下载进度、文件编辑器保存状态、云同步及更新器继续使用各自已有状态界面；本次未将这些长流程整体改造成浮动提示。

## 手动验收

| 入口与操作 | 预期结果 |
| --- | --- |
| AI 设置：保存厂商、预算、通知偏好、续聊偏好 | 完成后原窗口出现一次“操作成功 / 已保存”，连续重绘不重复提示 |
| AI 预算：输入无效数字并保存；厂商：缺少模型或默认组合 | 出现警告，保持草稿；需要选默认组合时继续原有选择流程 |
| AI 厂商：测试不可达地址；保存时模拟配置目录不可写 | 显示失败原因，不提前出现成功；页内错误仍可查看 |
| AI 厂商：刷新模型、确认清除 Key、删除非默认且未使用的厂商 | 实际完成后显示对应结果；取消确认不显示成功、不执行操作 |
| 保存期间切换设置页、另开窗口或关闭原窗口 | 提示只在原窗口；后续请求不覆盖上一请求结果，关闭窗口不将提示发送到其他工作区 |
| 设置 → 代理：保存有效配置、输入缺少字段的配置 | 有效配置写入完成后提示“代理设置已保存”；缺少字段时警告 |
| AI 消息/代码/工具步骤、审计详情/引用、SFTP 复制路径 | 剪贴板内容正确，原窗口提示“已复制到剪贴板”，提示不展示复制内容 |
| 测试目录：新建文件和文件夹、重命名、改权限、删除 | 每次完成提示具体结果，列表继续刷新；不可写目录显示错误；删除进度不重复弹出 |
| SFTP 输入含斜杠名称、非法权限；常用命令留空提交 | 警告可见、对话框不关闭、输入内容保留 |
| 深浅主题、中英文、小窗口、多窗口 | 四类图标/标题清晰，长错误可读，通知不抢焦点，关闭按钮与自动隐藏正常 |
