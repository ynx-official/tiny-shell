## 确认依据与范围

用户在 2026-10-12 确认 MCP 设置改版效果图，并授权按该方向实施。目标是缩短原来的长页面，让授权、客户端接入和待处理任务容易查找。沿用 Rust / GPUI、awesome-design-md 的 sentry 风格，以及项目已有主题、系统字体和 8px 间距。

同日用户追加三张权限卡片参考图，要求调整这一区域并更换 MCP 菜单图标。该次修改限于样式与点击范围；参考图中的 FileTerm 权限描述不作为 TinyShell 的业务规则。

本次调整设置交互和客户端配置展示，保留三种权限模式、动态全部连接、目标摘要校验、本机注册秘密、任务审批和审计保留规则。客户端检测、按客户端权限以及自动修改外部配置仍在本次范围之外。

## 页面与状态

页面使用「访问权限」「客户端接入」「任务与记录」三个页签。顶部启用开关、桥接状态、当前模式、授权数量和紧急停止入口保持可见，活动页签内容独立滚动。桥接失效或读取失败时保留页面和错误提示；不能读取有效策略时禁用策略修改入口。

关闭 MCP、桥接已就绪、桥接不可用分别显示实际状态。等待用户的任务在页签与顶部显示数量，顶部提醒可直接切换到任务页。紧急停止沿用直接执行行为，只取消本机任务和关闭 AI 会话，不承诺已经结束远端进程，也不关闭 MCP 开关。

## 访问权限

- 三种模式使用等宽单选卡片，标题与说明放在卡片内，整张卡片可点击；选中态使用参考图的蓝色细边和浅色底。保持当前应用背景、字体与文本颜色，悬停和焦点沿用组件状态。宽窗口横向排列，窄窗口或大字号改为纵向。
- 说明按扣除单选图标、间距和内边距后的剩余宽度自动换行；卡片保留最小高度，内容增加时自然增高，不固定高度裁剪文字。
- 卡片下方显示独立提示条：只读和受控执行使用蓝色保障提示，完全访问使用橙色风险提示。提示文字对应 TinyShell 的真实规则，保留原来的三种模式名称及完全访问确认要求。
- MCP 菜单使用现有图标库的连接节点图标 Network，替换原来的 Globe；没有增加新图标资源或改变代理页图标。
- 连接按名称、分组、主机、用户名和端口搜索，多词同时匹配，不区分大小写；可以只显示已授权连接。
- 有效授权计数始终针对当前全部 SSH 连接，不随搜索改变。
- 连接列表独立滚动，名称与地址分层显示，长名称可通过提示查看全文。
- 授权状态区分已授权、未授权和目标变化后需要重新授权。
- 「选择当前结果」「取消当前结果」只作用于可见结果；结果为空时按钮禁用。批量操作进入指定连接模式，未来新增连接不会继承授权。
- 从全部模式切回指定模式，先保留其余当前有效授权，再执行勾选操作。已删除或目标变化的连接不会被重新授权。
- 在提交选择时重新核对连接 ID 和目标摘要，连接在其他窗口变化后拒绝按旧行授权；提交前读取最新策略，避免用旧的整个策略覆盖其他窗口的修改。
- 重复选择已经授权的结果不增加策略版本，避免无变化操作打断任务。

完全访问和全部连接仍通过统一确认弹窗说明后果。授权更新沿用现有引擎的即时生效与会话失效行为；首次默认关闭、只读、零授权。

## 客户端接入

「添加客户端」菜单提供 Claude Code、Codex CLI、OpenCode 和通用 MCP 客户端。重复选择同名客户端优先展示其已有有效注册，不重复签发秘密；已有多个同名注册仍逐条展示，以短 ID 区分。已撤销注册默认折叠，保留原始记录。

注册后立即展示该注册的配置预览与使用说明。复制操作再次检查注册是否有效，并给出完成或失败反馈。配置只包含桥接入口与非秘密 ID，不包含本机接入秘密。沿用现有源码运行、完整安装包和 AppImage 入口选择。

客户端配置格式按本次查阅的官方资料生成：

| 客户端 | 展示格式 | 应用方式 |
| --- | --- | --- |
| Codex CLI | TOML 的 mcp_servers.tiny-shell、command 和 args | 合并到 ~/.codex/config.toml 并重新加载客户端 |
| OpenCode | JSON 的 mcp.tiny-shell，type: local 与包含程序及参数的 command 数组 | 合并到 opencode.json 或 opencode.jsonc |
| Claude Code | mcpServers.tiny-shell JSON | 合并到项目 .mcp.json 并遵循客户端审批提示 |
| 通用 MCP 客户端 | mcpServers JSON | 按具体客户端格式合并桥接程序与参数 |

这些入口只完成本机注册和配置导出；已注册、已复制都不等于客户端已经连接。撤销使用统一确认弹窗，说明旧配置失效及对应任务、会话停止，其他注册不受影响。

## 任务与记录

任务按待处理、进行中、已结束分组。待处理任务直接展开，其他任务按需展开；审阅显示客户端、目标连接、完整命令或原文件与待写入内容。长命令和配置使用等宽、双向可滚动区域，不截断提交的内容。文件内容采用有明确标题的前后对照，未增加文本 diff 算法。

补充凭据、批准和拒绝继续使用现有引擎；批准不是执行完成，反馈提示用户查看后续状态。错误保留代码并增加双语解释。不确定结果提示先检查远端。

操作记录默认折叠，按最近优先展示时间、客户端名称、连接名称、操作类型和状态。已移除连接有明确占位，历史仍仅保存元数据。清空记录使用统一确认，提示不可恢复，并明确不会撤销授权或停止当前任务。

## 验收标准

1. 三个页签独立展示对应操作，顶部紧急停止和待处理入口不会被长列表挤走。
2. 搜索、仅授权筛选与空结果状态正确，批量选择不影响隐藏连接或未来新增连接。
3. 从全部模式取消一条连接时，其余有效授权保留；变化的目标不能自动继承旧授权。
4. 相同连接重复选择不改变策略版本；模式与范围切换保留现有确认要求。
5. 已撤销注册折叠、同名注册可区分，注册及复制状态不伪装成客户端连接状态。
6. 三类客户端配置保留同一桥接入口、参数和非秘密注册 ID，Windows 路径正确转义。
7. 任务审阅能查看完整命令和文件内容，失败、拒绝、批准及紧急停止均有反馈。
8. 中英文、主题、窗口大小和字号检查按实际执行结果记录，未完成的原生验证不得视为通过。

## 独立原生预览

运行 cargo run --locked --example mcp-permissions 可查看复用生产组件的权限卡片预览。支持主题、语言、字号、窗口大小和禁用状态切换；点击权限卡片只修改预览状态，不读取用户配置、不更新 MCP 策略，也不连接远程服务。

追加 -- --compact 可在默认窗口中固定 710px 卡片内容区，复现设置页面中三张窄卡片的说明换行场景。
