## 默认组合规则

1. 默认值由厂商 ID 和模型 ID 共同标识，厂商名称和模型名称相同不会使不同厂商的模型混淆。
2. 有已启用且含模型的厂商时，保存必须指定一个有效组合；不自动选择第一个模型，也不自动跳到其他厂商。
3. 停用当前默认厂商、移除默认模型后，清空对应草稿选择并要求重选。没有可用厂商时允许无默认；尚未配置也允许无默认。
4. 删除已保存的默认厂商前，如果还有其他可用厂商，先选择并保存替代默认组合。删除最后一个可用厂商允许清空默认。删除失败保留当前编辑对象并显示原因。
5. 更改默认只影响之后创建的新会话，已有会话的模型选择、消息和运行中任务不改动。

## 配置兼容性

不改变配置 JSON 结构或云同步协议。继续由唯一的 `Settings.default_provider` 指向一个厂商，该厂商的 `default_model` 给出模型；领域接口统一返回 `ModelSelection`，拒绝缺失、已停用或不属于该厂商的模型。

其他厂商的旧 `default_model` 字段为旧版本与同步校验保留，不作为其他全局默认，也不在界面显示“默认”状态。旧配置直接加载原有效组合；无效组合显示待选择，不悄悄替换。服务层在持久化锁内复核组合，厂商和默认设置使用同一次配置文件原子写入。

本次不修改 API Key 加密、凭据端点绑定、同步权限、会话权限、历史加密或发布版本号。
