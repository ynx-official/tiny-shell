# Windows 安装版在线更新

> 状态：Review
> 最后更新：2026-10-22
> 关联：[构建与打包](../05-operations/build-and-package.md)、[统一确认弹窗](confirmation-dialogs.md)、[通用操作反馈](operation-feedback.md)

## 已确认范围与原因

用户确认 Windows 安装版改用可见的正常安装向导，沿用当前安装目录覆盖升级，同时修正提示文案并保存完整安装日志。首次改动不编译、构建、打包或运行真实应用与安装器；2026-10-22 用户随后授权构建 Windows 安装包，真实安装由用户手动验收。

此前后台使用 `/VERYSILENT /SUPPRESSMSGBOXES`，安装错误可能按默认选项中止。2026-10-22 本机两次更新日志记录退出码 5，只能确认安装取消或中止，尚不能确定底层触发原因。此前下载完成即显示“更新已安装”，也不符合实际进度。

## 用户流程

1. 点击“下载更新”，保持既有下载大小与 SHA-256 校验。
2. 下载及校验完成后，更新窗口和设置页均显示“更新已下载，等待安装”。Windows 安装版操作为“立即安装”；其他安装类型仍执行安装并重启，文案同步说明真实阶段。
3. 使用统一确认框提示将关闭应用、断开当前连接，并提醒保存工作、等待传输结束。取消确认不退出、不启动安装器。
4. 确认后启动隐藏的辅助进程；应用退出后，辅助进程以正常窗口打开已下载的 Inno Setup 安装包。通过 `/DIR` 传入当前可执行文件所在目录，通过 `/LOG` 指定独立详情日志；路径参数完整引用，兼容空格、中文、单引号和方括号。
5. 安装向导展示进度、错误和完成页。保留 `/NORESTART`，不自动重启系统；用专用退出码区别“需要重启系统”和安装完成。
6. 完成页的“启动 TinyShell”选项由安装器处理。辅助脚本只等待安装器自身退出，不等待它启动的应用，也不再次启动应用。
7. 安装器退出码为 0 且原目录程序版本匹配目标版本时，记录已完成并清理本次下载包、辅助脚本；保留两份日志。取消、中止、失败或需要系统重启时保留安装包，便于手动重试，不报告成功，也不强制打开旧程序。

原有 Inno Setup AppId、用户安装模式、快捷方式与配置存储保持不变，不先卸载、不删除用户数据。安装脚本本身沿用已有安装目录和任务选项记忆行为。Windows 便携版、macOS、Linux 的安装执行逻辑不变。

## 错误与日志

- 辅助进程启动前失败：当前窗口通过 `Feedback` 提示具体原因，保留下载完成状态和确认框供重试，不误报成“检查更新失败”。
- 应用退出后：安装器展示它自己的错误；辅助进程启动安装器失败、异常退出或版本不匹配时，使用随应用语言生成的系统提示，列出安装包、更新日志、安装详情日志和错误原因。
- 退出码 2 / 5：记录取消或中止，保留原退出码与文件。码 5 不推断为用户主动取消，因为它也可能表示选择中止安装错误。
- 退出码 3010：记录需要系统重启，不提前校验旧文件或宣称新版本已生效。
- `%TEMP%\tiny-shell-update-<唯一标识>.log`：时间、目标路径、目标版本、安装包位置、详情日志位置、退出码和版本核对结果。
- `%TEMP%\tiny-shell-update-<唯一标识>.setup.log`：Inno Setup 的文件替换、占用和安装动作详情，仅在安装器开始处理日志参数后生成。

两份日志使用相同标识关联，成功后也保留；临时目录清理仍由系统或用户管理。日志不写连接配置、密码或令牌，但包含本机安装路径，分享前应按需脱敏。

辅助脚本正文独立放在 `src/app/updater/windows_setup_update.ps1`，由 Rust 嵌入并提供已转义的路径、版本与本地化文案。生成脚本使用 UTF-8 BOM，避免 Windows PowerShell 5.1 将中文路径或文案按 ANSI 误读。

## 手动验收

| 入口 / 操作 | 预期结果 |
| --- | --- |
| 更新窗口与设置 → 在线更新：下载完成 | 显示“更新已下载，等待安装”和“立即安装”，没有提前安装成功的提示；中英文一致 |
| 点击立即安装，在应用确认框取消 | 应用和会话保持原状，安装包保留，可以再次确认 |
| 确认安装，原目录含空格或中文 | 应用退出，显示正常安装向导；目标为原目录，升级完成版本正确，连接配置保留 |
| 完成页勾选 / 取消勾选启动应用 | 勾选只启动一次；不勾选保持关闭，辅助进程退出且日志落盘 |
| 向导中取消、安装过程中取消 / 中止 | 不误报成功，不自动打开旧程序，安装包和日志保留，可手动重试 |
| 文件被其他程序占用或目录不可写 | 安装器显示具体错误与处理选项；详情日志可定位文件操作原因，不静默跳过 |
| 安装器无法启动或安装后版本不匹配 | 可见失败提示，包含日志和保留安装包位置，不删除包、不自动重启程序 |
| 系统要求重启才能替换文件 | 不自动重启系统；记录专用退出码，不报告已验证成功 |
| Windows 便携版、macOS、Linux | 保持原安装机制，下载完成文案准确，操作仍为安装并重启 |

已经运行的旧版本仍使用旧的更新代码。这次改动需随后续安装包交付；若旧更新流程继续失败，可手动运行官方安装包覆盖安装一次。
