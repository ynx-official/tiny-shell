# 快速连接浮层

> 状态：Review  
> 最后更新：2026-09-30  
> 关联：[文档索引](../README.md)、[项目规范](../../AGENTS.md)

## 用途与布局

标签栏文件夹按钮打开主窗口内的快速连接浮层，用于搜索并打开已保存连接。
沿用项目 Sentry 风格和当前主题颜色，保持原生桌面应用的信息密度。

- 浮层最大宽度 400px，紧贴标签栏入口，使用细边框和 8px 圆角。
- 标题显示所有已保存连接的总数，避免把折叠分组后的可见数量误认为全部连接。
- 搜索框高度 36px，提供搜索图标、清空按钮和聚焦边框。
- 分组行高 32px，显示展开箭头和文件夹图标；连接行高 48px，以两行显示名称和地址。
- 列表高度随内容收缩，最多 320px，并为小窗口留出顶部和底栏空间；超出后在列表内部滚动。
- 底栏显示方向键选择、Enter 连接提示及管理连接入口。搜索无结果时显示居中的空状态。

## 交互与约束

沿用已有搜索、分组展开、单击连接、键盘选择、Esc 和点击外部关闭行为。
管理连接仍打开现有管理窗口。此次调整不改变认证、会话配置、数据格式或存储。

浮层通过 `use_keyed_state` 保存临时 UI 状态，该 API 已将子状态通知转发给主窗口。
禁止再反向监听主窗口并无条件通知浮层，以免形成启动刷新循环。
