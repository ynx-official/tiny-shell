# 快速连接浮层

> 状态：Review  
> 最后更新：2026-09-30  
> 关联：[文档索引](../README.md)、[项目规范](../../AGENTS.md)

## 用途与布局

标签栏文件夹按钮打开主窗口内的快速连接浮层，用于搜索并打开已保存连接。
沿用项目 Sentry 风格和当前主题颜色，保持原生桌面应用的信息密度。

- 浮层宽度约为主窗口的 44%，常规范围为 600–760px；小窗口下保持在窗口内。紧贴标签栏入口，使用细边框和 8px 圆角。
- 标题显示所有已保存连接的总数，避免把折叠分组后的可见数量误认为全部连接。
- 搜索框高度 38px，提示可搜索名称、主机或用户，提供搜索图标、清空按钮和聚焦边框。标题、搜索与列表使用 16px 水平留白。
- 分组与连接均使用 32px 单行、13px 正文和 16px 图标；后续顶层分组前增加 4px 间距。连接名称、地址 / 端口、用户三列按 47% / 36% / 17% 分配空间。地址使用 12px 等宽字体，IPv6 地址加方括号后显示端口；树形缩进只占名称列，悬停可查看完整信息。
- 分组名称适当加重，选中项保持整行高亮，悬停选中项时保留选中色。
- 每次展开或折叠都会重新计算内容高度。浮层保持顶部锚点、向下增长，直到主窗口底部的可用空间用完后才启用列表滚动；搜索、列标题和底栏始终留在列表外。
- 底栏显示方向键选择、Enter 连接提示及管理连接入口。搜索无结果时显示居中的空状态。

## 交互与约束

沿用已有搜索、分组展开、单击连接、键盘选择、Esc 和点击外部关闭行为。
管理连接仍打开现有管理窗口。此次调整不改变认证、会话配置、数据格式或存储。

2026-09-30 根据 FinalShell 截图反馈，将早期 400px 窄面板、双行连接及 320px 列表上限替换为树形列表和基于窗口可用空间的自动高度。同日用户审阅并确认适中密度效果图，进一步将 24px 四列紧凑版调整为 32px 三列版，增加分组和横向留白。这里的“不遮挡”指列表不被底栏盖住、不超出主窗口边界；作为浮层仍会覆盖其后方的工作区。

浮层通过 `use_keyed_state` 保存临时 UI 状态，该 API 已将子状态通知转发给主窗口。
禁止再反向监听主窗口并无条件通知浮层，以免形成启动刷新循环。

## 验证

六项布局与地址检查通过，覆盖展开后超过旧 320px 上限、折叠收缩、窗口缩小时预留底栏、32px 行高、分组间距计入内容高度、三列宽度、窄窗口边界和 IPv6 地址显示。

- `cargo fmt --all -- --check`、`cargo clippy --locked --all-targets -- -D warnings` 和 `cargo build --locked` 通过。
- `cargo test --locked --all-targets`：526 项通过，1 项手动基准测试按既有配置忽略。
- Windows 原生窗口实测：32px 行高、顶层分组间距及三列对齐正常；多级展开自动增高；达到窗口底部后滚动可完整显示最后一项；折叠自动回缩；选中项在悬停时保持整行高亮。
- `scripts/test-windows-startup.ps1 -Executable target/debug/tiny-shell.exe` 通过，启动后连续 10 次采样保持响应。
