## 整体工作区

- 展开侧栏默认宽度为 `232px`，可在 `216px` 至 `320px` 之间拖动；读取已保存宽度时必须钳制到该安全范围，避免主机信息和监控模块进入不可读状态。折叠侧栏保持 `52px`。
- 品牌区左对齐到侧栏内容轴；主机 IP、连接地址和运行时间使用固定标签列。连接地址始终单行显示，空间不足时在末尾显示省略号，并可悬停查看完整地址。
- 普通模式下终端画布与 SFTP 面板使用同一内容边线和可拖拽分隔线，不把终端额外包成内缩卡片；Clean 模式可保留轻量内边距和圆角，以表达沉浸工作状态。
- 监控位于侧栏或隐藏时，下方面板默认高度为 `248px`、最小高度为 `180px`；监控位于底部时包含额外 `80px` 监控条，因此默认高度为 `328px`、最小高度为 `260px`。切换监控位置时按这 `80px` 差值补偿，保持 SFTP 实际可用高度不变。
- 普通模式的 SFTP 展开/收起入口归属底部状态栏；终端浮动工具条只在 Clean 模式保留 SFTP 入口。终端工具条使用 `8px` 圆角和 `8px` 边距，避免与下方面板形成无归属的悬浮胶囊。
- 侧栏监控分组使用 `8px` 组间距，资源、进程、网络和磁盘标题采用统一的 `28px` 紧凑高度；网络图表保持次要层级，不得挤压底部磁盘信息。

## 连接 Tab

- 仅原生标题栏模式使用紧凑连接 Tab；集成标题栏模式保持现有尺寸。
- 原生模式连接 Tab 的最小宽度为 `96px`，内部元素间距和水平内边距均为 `4px`。
- 原生模式标题按内容自然宽度展示，单个标题最大宽度为 `192px`；短标题不会占用统一的平均配额，多连接超出标题栏时沿用现有横向滚动。
- 连接标题始终单行显示，仅当标题自身超过 `192px` 上限时在末尾显示省略号；悬停可查看完整连接标题。
- 原生模式关闭按钮不保留额外右边距。
- 连接状态圆点、选中指示、悬停、关闭、右键菜单和拖拽行为不得因密度调整而改变。

## SFTP 文件区域

- 视图/操作栏与路径栏均为 `32px` 高；视图栏使用标签栏背景，路径栏使用工作区背景，以避免连续多层灰色横条。路径、返回操作和表格内容保持同一水平轴线。
- 左侧目录区默认宽度为 `236px`、最小宽度为 `120px`；左右区域之间使用 `1px` 可拖拽分隔条，右侧文件表至少保留 `320px`，因此左侧可在剩余空间内自由拉宽。右侧变窄时大小列和修改时间列可压缩到安全下限，名称列始终保留可辨认空间并继续使用省略号。调整结果在当前窗口生命周期内保持，不新增跨重启持久化。
- 左侧“远程文件”作为目录列表表头，使用与右侧文件列表表头相同的 `26px` 高度、背景、底边、字号和文字颜色；分隔条从两侧表头顶部贯穿内容区，但不穿过上方路径栏。
- 目录树名称保留完整原文并始终单行显示，不换行、不省略；超出目录区时通过树内横向滚动查看，内容缩短后自动钳制到有效范围。
- 目录树同时支持纵向与横向滚动；仅对应方向存在溢出时提供滚动条，滚动时显示并在空闲后淡出。横向浏览支持滚动条拖动、触控板横向手势以及 `Shift + 滚轮`。
- 切换目录或连接时回到目录树最左侧；目标目录已经可见或部分可见时保持当前纵向位置，只有完全离开视口时才做最小滚动使其贴近最近边缘。展开或收起节点时保留当前横向位置。
- 目录层级保持每级 `15px`、行高 `30px`、展开命中区宽 `16px`，使用标准 `ChevronRight` / `ChevronDown` 图标表达展开状态；祖先延续线保持低对比度，当前节点折线略强，避免形成表格栅栏感。
- 目录行至少铺满当前视口；非当前行使用轻量整行悬停反馈，当前目录使用较浅的整行选中反馈且不被悬停色覆盖。
- 右侧文件列表名称始终单行显示，超出可用宽度时在末尾显示省略号；文件大小、修改时间、选择框、文件类型图标和行交互保持现有布局与行为。
- 点击目录、点击 Chevron、右键菜单、排序、隐藏文件过滤和根目录行为保持不变。

## 验收标准

- 在约 `1172×741` 的窗口中，展开侧栏后连接地址不换行，终端和 SFTP 左右边线一致，底部磁盘区不被状态栏遮挡；在 `1024×640`、`1366×768` 和 `1600×900` 下不出现布局重叠或不可操作控件。
- 从底部监控切换到侧栏或隐藏时，下方面板减少 `80px`；反向切换时增加 `80px`，SFTP 列表的实际可用高度保持稳定。SFTP 最小化后恢复时按当前监控位置使用正确默认高度。
- 普通模式可从 SFTP 底部状态栏展开或收起面板，终端浮动工具条不显示重复入口；Clean 模式隐藏状态栏后仍可从终端工具条恢复 SFTP。
- 在原生标题栏模式打开多个连接时，连接 Tab 比集成模式更紧凑；短标题按内容自然收紧，标题可展示到 `192px`，超过上限才省略且长标题不会无限撑宽。
- 在集成标题栏模式下，连接 Tab 的既有宽度与间距不变。
- 在 `120px`、`160px`、`236px` 三档目录区宽度以及拖拽加宽后，长英文、中文和深层目录名称均保持单行且不出现省略号，可通过横向滚动查看完整名称。
- 左右表头高度、背景、底边和文字层级一致；分隔条可拖至左侧最小宽度及右侧 `320px` 安全边界，拖动时光标和激活线反馈清晰；目录树滚动视口在分隔条命中区前保留 `4px` 安全间隔。
- 展开、收起或切换隐藏文件后，目录分支引导线连续、末尾节点无多余尾线，根节点不显示无意义分支。
- 目录行的悬停与选中背景铺满可见宽度；切换目录或连接回到最左侧，选中已可见目录不改变纵向位置，完全不可见时只滚动到最近边缘，展开或收起保留横向位置。
- 目录树静止时滚动条不持续抢占视觉注意，滚动后可继续拖动；树滚动条与分隔条的命中区互不干扰，祖先引导线弱于当前节点折线。
- 缩窄右侧文件列表后，长文件名保持单行并以省略号结束。
- Tab 和 SFTP 行的选中、悬停、点击、右键与拖拽操作仍可正常使用。
