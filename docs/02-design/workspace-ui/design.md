## 整体工作区

- 展开侧栏默认宽度为 `232px`，可在 `216px` 至 `320px` 之间拖动；读取已保存宽度时必须钳制到该安全范围，避免主机信息和监控模块进入不可读状态。折叠侧栏保持 `52px`。
- 品牌区左对齐到侧栏内容轴；主机 IP、连接地址和运行时间使用固定标签列。连接地址始终单行显示，空间不足时在末尾显示省略号，并可悬停查看完整地址。
- 普通模式下终端画布与 SFTP 面板使用同一内容边线和可拖拽分隔线，不把终端额外包成内缩卡片；Clean 模式可保留轻量内边距和圆角，以表达沉浸工作状态。
- 监控位于侧栏或隐藏时，下方面板默认高度为 `248px`、最小高度为 `180px`；监控位于底部时包含额外 `80px` 监控条，因此默认高度为 `328px`、最小高度为 `260px`。切换监控位置时按这 `80px` 差值补偿，保持 SFTP 实际可用高度不变。
- 普通模式的 SFTP 展开/收起入口归属底部状态栏；终端浮动工具条只在 Clean 模式保留 SFTP 入口。终端工具条使用 `8px` 圆角和 `8px` 边距，避免与下方面板形成无归属的悬浮胶囊。
- 侧栏监控分组使用 `8px` 组间距，资源、进程、网络和磁盘标题采用统一的 `28px` 紧凑高度；网络图表保持次要层级，不得挤压底部磁盘信息。

## 连接 Tab

- 仅原生标题栏模式使用紧凑连接 Tab；集成标题栏模式保持现有尺寸。
- 原生模式连接 Tab 的最小宽度为 `96px`，内部元素间距和水平内边距均为 `4px`。
- 原生模式标题按内容自然宽度展示，单个标题最大宽度为 `192px`；短标题不会占用统一的平均配额，多连接超出标题栏时沿用现有横向滚动。
- 连接标题始终单行显示，仅当标题自身超过 `192px` 上限时在末尾显示省略号；悬停可查看完整连接标题。
- 原生模式关闭按钮不保留额外右边距。
- 连接状态圆点、选中指示、悬停、关闭、右键菜单和拖拽行为不得因密度调整而改变。

## SFTP 文件区域

- 视图/操作栏与路径栏均为 `32px` 高；视图栏使用标签栏背景，路径栏使用工作区背景，以避免连续多层灰色横条。路径、返回操作和表格内容保持同一水平轴线。
- 左侧目录区默认宽度为 `236px`、最小宽度为 `120px`；左右区域之间使用 `1px` 可拖拽分隔条，右侧文件表至少保留 `400px`，因此左侧可在剩余空间内自由拉宽。右侧变窄时大小、权限和修改时间列可压缩到安全下限，名称列始终保留可辨认空间并继续使用省略号。调整结果在当前窗口生命周期内保持，不新增跨重启持久化。
- 左侧“远程文件”作为目录列表表头，使用与右侧文件列表表头相同的 `26px` 高度、背景、底边、字号和文字颜色；分隔条从两侧表头顶部贯穿内容区，但不穿过上方路径栏。
- “远程文件”表头右侧提供紧凑的定位图标；仅在用户主动点击时将当前目录水平复位到最左侧并在目录树视口内居中，普通目录选择仍遵循最小滚动规则，不得自动跳到顶部。
- 目录树名称保留完整原文并始终单行显示，不换行、不省略；超出目录区时通过树内横向滚动查看，内容缩短后自动钳制到有效范围。
- 目录树同时支持纵向与横向滚动；仅对应方向存在溢出时提供滚动条，滚动时显示并在空闲后淡出。横向浏览支持滚动条拖动、触控板横向手势以及 `Shift + 滚轮`。
- 切换目录或连接时回到目录树最左侧；目标目录已经可见或部分可见时保持当前纵向位置，只有完全离开视口时才做最小滚动使其贴近最近边缘。展开或收起节点时保留当前横向位置。
- 目录层级保持每级 `15px`、行高 `30px`、展开命中区宽 `16px`，使用标准 `ChevronRight` / `ChevronDown` 图标表达展开状态；祖先延续线保持低对比度，当前节点折线略强，避免形成表格栅栏感。
- 目录行至少铺满当前视口；非当前行使用轻量整行悬停反馈，当前目录使用较浅的整行选中反馈且不被悬停色覆盖。
- 右侧文件列表名称始终单行显示，超出可用宽度时在末尾显示省略号；权限列位于大小列之后，使用等宽字体和 `rwxr-xr-x` 形式展示九位 POSIX 权限，保留 setuid、setgid 与 sticky bit 的 `s/S/t/T` 语义；修改时间、选择框、文件类型图标和行交互保持现有布局与行为。
- 已识别的文本文件仍可双击直接进入内置编辑器；任意普通文件均可通过“打开方式 → 强制使用文本编辑器打开”尝试以文本打开，不改变未知文件双击时沿用系统关联的行为。超过编辑器硬限制的文件仍拒绝载入。
- 内置编辑器优先识别 UTF BOM，其次验证 UTF-8，再对常见中日韩和西欧旧编码进行自动检测。状态栏使用紧凑编码按钮显示当前结果，点击后弹出最高 `320px` 的可滚动编码列表；支持 UTF-8、UTF-8 BOM、UTF-16 LE/BE、GB18030、GBK、Big5、Shift_JIS、EUC-JP、ISO-2022-JP、EUC-KR/CP949、Windows-1252 和 ISO-8859-1。
- 手动选择编码时从首次打开或最近保存成功的原始字节重新解码，后续保存沿用该编码；存在未保存修改时必须先确认，不能静默覆盖编辑内容。无法由目标编码表达的字符必须阻止保存并显示错误，不得用替代字符静默损坏文件。
- 点击目录、点击 Chevron、右键菜单、排序、隐藏文件过滤和根目录行为保持不变。

## SFTP 常用命令

- 常用命令使用“左侧分类、右侧内容”的平面双栏结构：分类栏默认宽度约 `220px`，分类行高 `36px` 并使用 `8px` 列表内边距，内容超出后通过独立滚动句柄纵向滚动，并在实际溢出时保持滚动条可见；选中分类使用低对比背景和左侧强调线，不使用浮层卡片嵌套。
- 分类栏表头右侧提供紧凑的新增分类图标，悬停时显示“新建分类”提示；右侧头部显示当前分类名称与筛选后的命令数量，并提供命令搜索和“管理命令”入口。搜索同时匹配名称、备注和命令正文，忽略大小写。
- 命令以可换行排列的等尺寸卡片展示，所有卡片固定为 `280×76px`，末行不得通过弹性拉伸形成大小不一致。每张卡片包含终端图标、名称、实际命令正文和明确的“运行”操作；命令正文使用等宽字体，空间不足时名称与命令均单行省略，右侧卡片区独立纵向滚动。
- 右键分类项提供“新建分类”和“编辑”，分类列表空白区也提供“新建分类”并可编辑当前分类；右键命令卡片提供“新建命令”和“编辑”。命令为空或搜索无结果时，空状态命中面必须铺满整个右侧内容区，任意空白位置右键均可“新建命令”；存在命令时，卡片下方剩余空白区继续提供“新建命令”。新增与编辑继续复用既有对话框和保存规则，不增加旁路数据入口。
- 单击卡片在右侧同一内容区切换到紧凑详情与动态参数表单，关闭后返回卡片列表；不得在命令主区内再嵌套一套可拖拽分栏。双击和“运行”继续走既有发送流程，包含动态参数且尚未填写时不得绕过参数校验。右键编辑、分类管理和终端发送行为保持不变。
- 命令区沿用项目主题色、边框和 Sentry 紧凑密度，不复制参考图的大尺寸留白、品牌色或营销式卡片样式。

## 验收标准

- 在约 `1172×741` 的窗口中，展开侧栏后连接地址不换行，终端和 SFTP 左右边线一致，底部磁盘区不被状态栏遮挡；在 `1024×640`、`1366×768` 和 `1600×900` 下不出现布局重叠或不可操作控件。
- 从底部监控切换到侧栏或隐藏时，下方面板减少 `80px`；反向切换时增加 `80px`，SFTP 列表的实际可用高度保持稳定。SFTP 最小化后恢复时按当前监控位置使用正确默认高度。
- 普通模式可从 SFTP 底部状态栏展开或收起面板，终端浮动工具条不显示重复入口；Clean 模式隐藏状态栏后仍可从终端工具条恢复 SFTP。
- 在原生标题栏模式打开多个连接时，连接 Tab 比集成模式更紧凑；短标题按内容自然收紧，标题可展示到 `192px`，超过上限才省略且长标题不会无限撑宽。
- 在集成标题栏模式下，连接 Tab 的既有宽度与间距不变。
- 在 `120px`、`160px`、`236px` 三档目录区宽度以及拖拽加宽后，长英文、中文和深层目录名称均保持单行且不出现省略号，可通过横向滚动查看完整名称。
- 左右表头高度、背景、底边和文字层级一致；分隔条可拖至左侧最小宽度及右侧 `400px` 安全边界，拖动时光标和激活线反馈清晰；目录树滚动视口在分隔条命中区前保留 `4px` 安全间隔。
- 展开、收起或切换隐藏文件后，目录分支引导线连续、末尾节点无多余尾线，根节点不显示无意义分支。
- 目录行的悬停与选中背景铺满可见宽度；切换目录或连接回到最左侧，选中已可见目录不改变纵向位置，完全不可见时只滚动到最近边缘，展开或收起保留横向位置。
- 点击“远程文件”表头的定位图标后，当前目录在树内居中并回到最左侧；普通点击当前或其他目录时仍不跳顶。
- 目录树静止时滚动条不持续抢占视觉注意，滚动后可继续拖动；树滚动条与分隔条的命中区互不干扰，祖先引导线弱于当前节点折线。
- 缩窄右侧文件列表后，长文件名保持单行并以省略号结束。
- 文件权限表头与行数据严格对齐，普通权限和 setuid、setgid、sticky bit 均显示正确；权限列不会挤掉文件名的最小可辨认空间。
- UTF-8、UTF-8 BOM、UTF-16 LE/BE、GBK/GB18030、Big5、日文、韩文和 Windows-1252 样例打开后文字可读，状态栏显示识别结果；手动切换可重新解码，脏文件先确认，保存后再次打开保持所选编码。
- 未知扩展名文件可从右键菜单强制进入内置文本编辑器；默认双击行为和超过 `5 MiB` 的保护规则不变。
- 常用命令分类栏与右侧卡片区均使用独立滚动句柄，可通过滚轮和溢出时显示的滚动条上下浏览；分类行具备清晰留白，所有命令卡片宽高一致。右键分类项或其空白区可新增分类并编辑当前分类，右键命令卡片可新增或编辑命令；命令为空或搜索无结果时，右侧除滚动条轨道外的整个内容面均可稳定触发“新建命令”。表头新增图标、数量、搜索、管理入口和卡片命令正文在展开面板中可用，卡片不再以备注替代实际命令，搜索名称、备注或命令正文均能得到正确结果，空结果有明确反馈，动态参数命令不会被直接绕过校验发送。
- Tab 和 SFTP 行的选中、悬停、点击、右键与拖拽操作仍可正常使用。
