用户确认规划和 12 组页面预览后授权端到端实施。本次扩展原 MCP 首版范围外的内置聊天与模型配置；SSH 权限、审批和独立会话语义继续复用原实现，不改成终端按键注入。

## 交互与业务规则

- 纯净模式右侧增加 AI 图标；AI 和 Docker 共用右栏，切换保留状态。AI 默认宽 420px，可调整 360–600px，终端剩余空间不足 480px 时覆盖显示。
- 直接打开对话，返回按钮进入可搜索、重命名和删除的历史。面板隐藏不取消任务；停止按钮取消本轮，不自动重放已执行的变更。
- 输入区采用细边框、12px 圆角的主题背景容器，目标/权限、无独立边框的文本框、模型/发送控制均在框内。占位仅保留“描述问题或希望完成的操作…”，不显示 Enter 或 Shift+Enter 文案，原有快捷键行为保留。活动轮只禁用文本编辑和模型选择，停止按钮保持可用；输入区不会因禁用而变为整块灰底。
- 本轮尚无任何回复正文时，聊天区显示两行等待内容：第一行“AI 助手”，第二行“正在处理中”与三个闪烁点。收到首个正文字符后，正文替换等待文案，只在当前回复末尾保留闪烁点，不再额外增加助手标识或处理文案。工具执行、等待审批或后续模型请求期间，点跟随最新内容/步骤，并保持至整轮完成、停止或失败。不在输入区底部重复显示生成状态，取消与异常反馈留在聊天区。
- SSE 响应期间，聊天每次刷新都跟随最底部，保证最新正文和闪烁点可见；大段分片和 Markdown 重新排版也持续跟随。完成、停止或失败后恢复自由滚动，可回看上方历史。
- 对话首次发送后固定 SSH 目标。标签切换不改变目标；无 SSH 可以普通聊天。首版不读取人工终端、图片或思考参数。
- AI 设置管理多个 OpenAI 兼容 Provider、API 地址、模型、默认项与工具能力声明。请求采用 Chat Completions 和 SSE；仅用户主动请求时联网。
- MCP 设置改称 MCP / CLI。内置 AI 与外部客户端分别在“内置 AI / MCP·CLI”Tab 中启停并选择独立模式；AI 权限应用到所有对话，只有 MCP 选择授权机器。内置访问默认关闭，旧外部开关保持原值。
- 开启内置访问时说明远程内容会发送给所选模型服务；完全访问需要确认。命令和文件修改复用已有审批与任务记录。
- API Key 使用云同步隐私密码加密保存并参与配置同步；历史主密钥继续使用系统凭据存储，历史与审计仍只属于本机。未配置隐私密码的新 Key 仅临时使用。2026-10-12 用户确认的范围变化与兼容规则见[同步契约](../sync/ai-mcp-sync.md)。
- 删除历史需要确认；活动对话先请求停止。重启后未完成轮次标为中断，不自动执行。

## 实施与验收

### 工具步骤展示

2026-10-12 按用户截图反馈修订：连续工具调用在助手说明与最终答复之间显示为一组“执行步骤”。组内采用平面行与细分隔线，每步展示操作名、状态图标/文字及单行命令或路径摘要，替代重复的“展开工具结果”和底部状态列表。默认显示步骤，完整参数与结果收起；整组和单步均可折叠，切换时不发出工具请求。

运行使用加载图标，成功、失败与待确认使用主题状态色；取消、中断、超时、结果未知及未执行保持独立文案。待确认的审阅按钮放在组头，折叠后仍可进入原任务页。历史中重复的调用 ID 按消息位置区分；旧历史无关联字段时兼容已有调用顺序。

展开后的参数和结果按原样代码显示，可选择和复制，单块超过 220px 时内部滚动；不将工具正文渲染为可加载的图片或 HTML。原生预览命令为 `cargo run --locked --example ai-tool-steps`，使用生产组件和合成数据，不加载用户配置或请求网络。

步骤组保持内容高度，不参与聊天滚动区的纵向压缩。最终答复变长时增加滚动范围，不能把已完成步骤压成细线；完成后仍可展开查看结果。预览的“完成并显示长答复”操作可验证这一状态切换。

2026-10-12 输入区修订：用户明确移除先前移入占位文字的快捷键提示，并要求在聊天中显示处理动画。参考截图的输入容器排布，使用既有目标、权限、模型和发送/停止操作；截图中的参考终端、思考参数及额外代理模式不构成本次新增功能。

后续修订：用户明确等待内容需要换行；首次正文到达后只保留闪烁点，不能在输出后再次追加“AI 助手 / 正在处理中”。首次正文按当前用户轮判断，旧回复和工具结果不计入；后续模型轮也不恢复等待文案。点延续至整轮结束。之后用户明确 SSE 响应期间必须持续滚动到最底部，替代原来优先保留滚动位置的规则；非生成状态仍可回看历史。

按来源权限、模型及存储、聊天 UI、设置 UI、工具闭环与原生验证分片推进。每段对话单活动轮，执行预算耗尽时等待用户选择；所有参数完整接收并验证后才执行。数据文件原子写入且只允许当前用户访问，日志不包含 Key、聊天正文、命令输出或文件正文。

测试覆盖独立开关、目标绑定、跨对话隔离、审批失效、流式分片、取消与异常、凭据不可用、历史加密及历史不参与同步；新增 API Key/MCP 配置同步验收见[专项质量记录](../04-quality/ai-mcp-sync.md)。实际质量与平台结果记录于质量文档，不以设计预览替代运行证据。

2026-10-12 修订：用户明确 AI 全局权限、MCP 机器选择的边界，替代原共享授权设计，理由和验收变化见[需求修订](../01-requirements/ai-conversations.md)。

## 执行预算与暂停选择（2026-10-12 已确认）

2026-10-12 根据用户提供的快捷键子菜单截图修订：AI 设置采用既有侧栏分组导航，默认展开“模型服务 / 执行预算 / 通知提醒”。点击子菜单直接定位对应分组，保持与快捷键一致；不另建第二套设置路由或独立窗口。模型服务分组承载原 Provider 表单；执行预算分组直接展示工具与模型请求两个预算及保存按钮，移除原高级设置折叠；通知提醒分组仅承载通知开关、说明、测试与保存、系统反馈。

预算与通知分别拥有草稿，保存时合并最新已保存的另一组值，避免切换分组后相互覆盖；原 Provider 草稿、现有配置值及 AI/MCP 设置入口索引保留。工具预算默认 16 次，范围 1–128；模型请求预算默认 8 次，范围 1–64。输入非法值时显示双语错误并拒绝保存；当前轮固定发送时的预算，设置改变从下一轮生效。

预算只在确实需要下一次工具或模型请求时触发；正好用完预算但已完成回答时不弹窗。当前轮进入等待继续状态，停止闪烁点、保留停止入口与已有工具结果。所属主窗口在前台且没有其他弹窗时，通过统一 ConfirmationDialog 显示对话标题、累计已用次数、继续追加次数及模型用量提醒。按钮为“终止本轮”与“继续，再允许 N 次”；无点击保持暂停，弹窗级 Escape/Enter 禁用，按钮仍可用 Tab 聚焦并以 Enter/Space 操作。多个暂停按更新时间顺序处理，不覆盖既有业务弹窗。

继续只扩展触发暂停的对应预算，保留另一种预算、当前模型/目标快照、工具批次、SSH 会话、重复结果记录及不确定结果保护。终止取消后续工作，保留已完成结果，对已接收但未执行的批内工具写入未执行结果；不回滚远程变更，也不主动调用模型生成总结。对话内保留等待提示及两操作入口，隐藏面板不会取消暂停。

系统通知默认关闭，开启后仅在应用不在前台时提醒一次；发送提醒时不激活窗口。2026-10-12 用户要求增加快速处理按钮：通知提供“允许继续”和“拒绝并终止”，直接处理其绑定的当前暂停，免去返回应用后的再次确认。正文点击仍激活所属窗口并定位到对话。通知只显示通用说明及追加预算的用量提醒，不含目标或聊天内容。使用随机暂停 token 校验，过期、重复或未知动作不能恢复或终止其他轮次；关闭通知/超时保持暂停。测试通知显示相同按钮但不绑定对话，操作无业务副作用。按钮仅处理运行预算，不改变 SSH 模式，也不代替受控操作审批。

设置提供测试通知和发送/权限反馈；系统不允许通知、勿扰及发送失败时保留应用内提示。Windows 使用本应用标识的原生 Toast；macOS 使用 UNUserNotificationCenter，首次主动开启或测试时申请通知授权，继续按钮在锁屏时要求系统身份验证，要求已签名 .app 包。按钮的折叠和呈现方式由系统决定，应用内入口保留。Linux 保留应用内完整交互，系统通知开关与测试按钮禁用。

单响应超过 32 个工具调用使用独立的“模型响应超限”提示；预算继续不能绕过响应完整性、权限、重复调用或结果未知保护。实际验证范围及手动验收见[预算与通知验证](../04-quality/ai-execution-budget.md)。
