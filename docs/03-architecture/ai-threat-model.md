# 内置 AI 安全边界

> 状态：Review
> 最后更新：2026-10-12
> 关联：[实现契约](ai-conversations.md)、[MCP 原边界](mcp-contracts.md)、[验证记录](../04-quality/ai-conversations.md)

| 信任边界/风险 | 实现约束与验证方向 |
| --- | --- |
| 模型生成参数或远程正文诱导操作 | 模型与工具输出均视为数据；参数完整接收、JSON/Schema 验证后才进入 Engine。提示词不替代权限检查，受控操作由真实用户审批。 |
| 目标切换、跨对话读取任务或会话 | 首次发送固定目标，内部能力绑定 ID/摘要；引擎过滤连接，任务和会话仍以 client 隔离。授权摘要变更不能继承旧权限。 |
| 外部客户端冒充内置来源 | 内部能力不接受序列化/IPC认证，EngineHandler 拒绝 `ai:` 来源。 |
| 关闭再启用或 AI 模式变化恢复旧执行 | 内部能力绑定 AI 模式/启停代数；提交任务时再次检查，AI 变更只取消 AI 任务，网络请求检测能力撤销。MCP 权限、机器授权及启停独立，不撤销 AI 审批。 |
| API Key 误发、重定向、明文传输 | 地址变更必须提供新 Key；Key 查找与地址检查通过串行持久化锁执行。禁重定向、禁 URL 用户信息/查询串/片段；远程 HTTPS，本机 HTTP 需显式允许；无 Key 仅回环地址。 |
| 云端密钥搬移、错误密码覆盖及旧客户端抹掉配置 | 本地/云端 Key 绑定服务商 ID 与地址；隐私密码认证解密，未知明文密钥不导入；未解密远端 Key 阻止上传，恢复保留本地 AI 配置。v4 写入、v3 兼容读取，旧客户端拒绝 v4。见[同步契约](../sync/ai-mcp-sync.md)。 |
| Markdown 自动外连或本机图片读取 | 展示前按语法树转义图片节点与原始 HTML，代码和普通文本链接保留；没有自动图片加载。复制仍保留原正文。 |
| 历史篡改、文件交换或密钥丢失 | 认证加密、随机 nonce、UUID AAD、私有权限、拒绝符号链接和受限读取。无法解密保留原文件并警告，无明文回退。 |
| 删除后后台保存复活 | 取消活动轮次，串行删除与检查点；检查点要求内存中对话仍存在。 |
| 崩溃后的远程结果不确定 | 重启仅加载为中断状态，无自动重试；补齐工具协议结果未知占位，不重复 SSH 操作。 |

完全访问允许获准远程账号权限内的任意 Shell 命令，不能承诺禁止删除或数据外传；只读模式拒绝所有 Shell 字符串，仅提供既有目录与文本读取工具。内置开关启用说明包含数据送往所选 Provider、可能费用与完全访问无需逐次确认。

云同步隐私密码、系统凭据及认证加密保护静态数据；运行中应用仍必须持有 Key、聊天和工具结果。具备本机用户/管理员权限的恶意进程与已被攻陷的 Provider 不在静态加密的保护范围。用户主动发送内容及获准工具结果可由 Provider 处理；首版不读取人工终端，也不上传连接认证信息。

诊断日志仍只记录固定错误/操作元信息。用户已批准独立审计详细保留参数、命令与实际结果：正文脱敏后本机认证加密，API Key、密码、私钥和 proof 不保存；已知凭据文件正文遮蔽，导出脱敏明文需独立确认。审计不可落盘时阻止新的变更操作，查询明确为临时记录；脱敏不能识别所有业务秘密。具体边界见[审计契约](ai-usage-and-audit.md)。实际跨平台与真实模型服务验证范围以验证文档为准。
