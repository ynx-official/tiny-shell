## 运行中发现并修正的问题

- rusqlite 数字读取改用可校验的有符号整数转换，拒绝负数用量索引；修正 UI trait、下拉菜单返回类型、示例类型导入及 Clippy 问题。
- 已删除聊天的审计筛选原先被较新的工具事件抢先填为内部 ID。现在先读取模型标题快照，再回退到 ID；保留当前聊天的重命名结果。回归先失败、修正后通过，原生菜单复验显示合成会话标题。
- 审计独立窗口缺少统一确认框的渲染层，原生点击 JSON 导出没有出现确认框。现在在公共 Render 外层渲染，覆盖详情和设置分支。GPUI 回归验证两个页面的执行/取消按钮可见、取消关闭且不导出/清理；先失败、修正后通过。UI 回归隔离后台查询，避免真实存储线程唤醒 GPUI 的确定性测试调度器；存储与查询另由领域测试和原生预览覆盖。

## 原生审计窗口验证

使用 debug 专用 `--audit-preview`，复用生产面板及确认框，在随机临时目录中注入合成数据，不加载用户配置或启动模型/SSH 服务。通过 computer-use 检查中文浅色 1040×760、英文深色 760×600 客户区；预览关闭后进程退出。

- 用量：输入 300、输出 40、总量 340，模型请求 2 次、1 次用量未知；缓存 120、推理 8 没有重复计总量。
- 操作与审批：请求、待审批、已批准和完成时间线，以及预算拒绝记录可见；外部 MCP 来源筛选仅留下外部记录，并显示不计 Token。
- 详情：命令参数中合成密码为 `[REDACTED]`；160 行标准输出在受限高度内滚动；普通文件修改前/后及统一 diff 脱敏展示。
- 筛选与排布：会话标题快照下拉、按会话筛选、四个页签、窄窗口详情及正文导出确认框检查通过；留存默认 90 天、512 MiB，只读检查布局。
- CSV：通过原生保存框导出当前页 6 条合成摘要，脚本核对已知 300/40/340 用量、外部 `excluded` 和无合成秘密。
- JSON：通过原生确认框及保存框导出所选命令的完整 4 条时间线，脚本核对批准渠道、退出状态、标准输出，以及所有参数密码已脱敏。导出成功也产生管理审计事件。

两个合成导出文件保存在忽略的 `target/audit-summary-native-20261012.csv` 与 `target/audit-details-native-20261012.json`，未写入文档或用户配置。未用 UI 修改留存/脱敏规则或清理数据；已执行正则与启动恢复的相关领域回归，实际设置保存、独立清理及存储重试仍需后续端到端验收。此次原生证据只覆盖审计面板，不能代替真实主窗口、AI 设置、SSH 或 Provider 的端到端验收。

## 已运行的相关回归

- usage 缺失与零值、分项求和、缓存/推理不重复计总量。
- 空 choices 尾帧、同一块内元数据合并、后续正文失败时保留已收到用量。
- 模型请求重复更新只入账一次，外部工具不入 Token 汇总。
- 自定义表达式不破坏关联 ID，晚到的 queued 返回不覆盖执行终态。
- 成功轮询折叠，递归操作时间线包含子调用的原始外部请求。
- 磁盘/WAL 无原始命令及秘密、正确密钥重开、错误密钥与密文修改失败。
- 已知凭据文件正文和预览遮蔽，文件 diff 保留上下文与末尾换行变化。
- 启动时的结果未知只记一次，不重试远端动作。
- 权限批准/拒绝记录关联任务，拒绝后执行计数不增加。
- 审计不可用阻止变更，查询保留临时记录；替身不依赖系统凭据库。

## 剩余真实服务与平台验收

| 入口与步骤 | 预期与异常关注 |
| --- | --- |
| AI 新对话连续发送，触发工具后再次请求模型；点底部用量 | 分别列出真正的模型请求，汇总只按请求加一次；输入/输出与未知次数明确，流式输出和自动滚动正常。 |
| 历史 → 同一对话，重命名、关闭侧栏后重开 | 同一会话累计数保持，旧对话没有伪造用量；窄侧栏用量按钮不挤掉标题和重命名/删除按钮。 |
| 审计 → 按时间、机器、客户端、会话、分类、状态搜索，点一条命令 | 参数、用途、目标、审批、输出、退出状态及完整时间线可追踪；加载更早事件及刷新正确；长输出不撑坏窗口。 |
| 内置 AI 受控模式分别允许/拒绝，追加预算分别继续/终止；测试系统通知决定 | 权限与预算分开记录，渠道准确；拒绝、过期、撤销和未执行不得显示为成功；历史记录不直接重新批准，待审阅跳转到当前任务。 |
| 测试机器上创建/更新普通文件，另读取合成凭据文件 | create/update 分类正确，版本和脱敏差异可读；凭据正文/私钥/API Key/proof 不出现在审计、WAL、复制和导出中。不要用生产凭据验证。 |
| 外部 MCP 合法读取、错误参数、未知工具、授权失败和 GUI 不在线 | 外部参数或受限拒绝信息留下记录，外部显示不计 Token；不会影响内置 AI 全局权限。 |
| AI 设置 → 测试连接，再检查会话与操作列表 | 测试标为设置测试；该请求可能消耗服务 Token，但不增加聊天累计数；模型列表刷新不计生成请求。 |
| 审计设置 → 调整容量/周期/正则，再测试独立清理和导出 | 无效配置报错；CSV 仅当前页，JSON 完整操作需确认；聊天删除保留审计，审计清理保留聊天累计数，旧摘要清理不清独立审计。 |
| 隔离配置目录模拟凭据不可用、不可写或容量上限，恢复后点重试 | 明确临时/不完整状态，新命令/写入被阻止；不会明文回退，也不会自动重试 SSH；重新发起操作前确认存储恢复。 |
| 隔离实例中断有活动任务后重新启动 | 老任务标中断/结果未知，不重放；不要把本机中断当作远端未生效。 |

本轮未调用真实收费模型或真实 SSH，也未运行 macOS/Linux 构建。真实服务的用量尾帧、外部 MCP 实际客户端、任务审阅跳转、主窗口归属、大数据分页/容量及跨平台原生行为仍按上表验收；合成记录显示为成功不代表真实远端命令已经执行。
