## 本轮范围

实现三页签、固定桥接控制区、连接搜索及授权筛选、当前结果批量选择、注册折叠与配置预览、客户端配置格式适配、任务分组审阅、完整命令复制和操作反馈。保留现有默认值、权限矩阵、秘密存储、IPC、远程执行和审计保留规则。

页面状态独立保存在每个设置窗口的 keyed entity 中，搜索订阅跟随 entity 生命周期，不增加主窗口布尔状态或持久化配置。各页签与纯授权逻辑分模块维护。

## 审查结果

- 修改授权时读取最新策略，选择操作重新核对当前目标摘要，避免按旧行授予变更目标。
- 退出全部模式时只保留当前有效目标，单条取消不再连带清空其他授权。
- 没有变化的选择保持策略版本，已选模式和范围重复点击不再次提交。
- 注册菜单重复点击复用已有有效注册；复制前重新检查注册是否已撤销。
- 配置展示不输出注册秘密。Windows 路径经过序列化转义；既有 helper、嵌入主程序和 AppImage 入口选择保持。
- 模态确认复用 ConfirmationDialog；清空本机审计记录和撤销注册说明相应影响。
- 任务批准反馈只表示批准已提交；紧急停止和不确定结果提示不承诺远端进程已经终止。
- 历史只展示已有元数据，没有新增正文、命令或凭据持久化。

## 2026-10-12 说明文字换行修复

用户截图显示，710px 内容区中第一张和第三张卡片的说明越过右侧内边距。修复前先为独立原生预览增加 --compact 场景，构建日志为 target/mcp-wrap-before-build.log；用户提供的同场景预览截图确认可以复现。

原因是原单选组件内部的文字列使用整行 100% 宽度，额外的单选图标和间距没有从文字宽度中扣除。现改为可聚焦的整卡按钮，图标固定宽度，文字列占剩余空间并允许收缩；标题和说明自动换行，卡片使用最小高度与自然高度。原模式回调、重复点击跳过和禁用条件保持。

原生检查已观察到修复后的默认字号、中文、亮色主题、只读选中、710px 三列场景：三个说明全部完整显示，右侧保留内边距，蓝色选中状态与提示条正常。继续检查英文时，Computer Use 被用户按物理 Escape 中止；未再进行界面操作，已关闭本轮独立预览进程。英文、大字号、纵向排列、禁用状态和键盘交互仍未完成本轮原生检查，不能据此声称这些项目通过。
