## 重点手动验收

| 入口 / 场景 | 步骤 | 预期 |
| --- | --- | --- |
| 设置 → 在线更新 | 默认自动择优，点击检查更新 | 显示检测中，随后展示真实耗时和线路状态；选择最新可信版本中响应最快的源 |
| 手动测速 | 记录上次检查时间，点击重新测速 | 只刷新线路检测时间和结果；不改变检查时间、不下载，不覆盖已确定的版本 |
| 自动检查 | 分别使用启动和定时模式 | 每次检查先检测线路；通知偏好保持有效，禁用自动检查时仍能手动检查 |
| 固定线路 | 分别选择仅 GitHub、两条内置线路 | 仅 GitHub 不联系加速源；固定源失败不从其他源下载，无签名源可进行 GitHub 元数据核验 |
| 添加多条线路 | 在自动模式依次添加两个不同前缀；分别使用按钮和回车；重开设置 | 列表累积为两条；保存成功提示后清空草稿，重开仍存在；模式保持自动，两条都参与测速 |
| 地址校验 | 添加已有地址的大小写 / 默认 443 端口 / 结尾斜杠变体、内置地址；输入 HTTP、凭据、查询参数、本机地址 | 重复或非法值页内提示，不增加条目，不清空输入；空输入不可添加 |
| 固定自定义线路 | 在行内或下拉选择第二条，然后检查更新 | 选中状态一致，保存后提示成功，只探测 / 下载所选自定义线路（无签名仍需官方核验） |
| 逐条移除 | 固定第二条，移除第一条；再移除第二条，分别尝试取消与确认 | 取消无变化；删除非当前线路不改变固定选择；删除当前线路明确告知切回自动，保存完成后才更新列表并提示 |
| 保存失败 / 连点 | 在隔离配置目录模拟不可写；添加或移除，保存中连点、测速、下载；恢复权限重试 | 保存中显示状态且禁用冲突操作；失败提示在原窗口，原列表及选择保留，草稿不丢；成功不重复添加 |
| 窗口归属 | 主窗口及独立设置窗口分别添加；保存期间关闭发起设置窗口 | 两处使用相同已保存列表，反馈只属于发起窗口；关闭窗口不将成功提示转移到另一窗口 |
| 旧字段迁移 | 用包含单值 custom_prefix 的隔离配置启动，再添加 / 删除；重启 | 旧条目和固定选择保留，保存新列表；已删除条目不会因旧字段再次出现 |
| 缓存 / 签名错误 | 在隔离网络中模拟旧清单、错误签名、同版本错误哈希和无签名清单 | 旧源不优先；错误签名不可用；无签名且无法核验时不进入可安装状态 |
| GitHub 不可达 | 使用内置正确公钥的构建，提供有效签名镜像 | 可信镜像可完成检查；没有有效签名时明确报告无可信线路 |
| 自动下载切线 | 发现新版本后下载，模拟首条线路连接失败 / 503 | 当前线路提示切换，进度从零开始；版本、附件、大小和摘要保持一致 |
| 完整性失败 | 模拟长度不符或错误 SHA-256 | 明确失败，不切线掩盖错误，不准备安装 |
| 取消与重试 | 下载中取消，立即重试 | 旧任务不覆盖新进度，不在取消后启动备用线路 |
| 等待安装 | 下载完成后等待定时检查，重开设置和更新弹窗 | 保留已验证安装包及安装按钮，禁用再次检查和改线路 |
| 界面 | 深浅主题、中英文、最小窗口与长自定义域名 | 信息可读，线路名可省略，表单不溢出，按钮忙碌状态正确 |
| 平台回归 | Windows 安装 / 便携、macOS 基础 / RDP、Linux AppImage / tar.gz | 延续现有选包、校验、安装确认和取消规则，不串包 |

## 获准后的验证入口

```text
cargo test --workspace --locked --all-targets
cargo clippy --workspace --locked --all-targets -- -D warnings
python -m unittest scripts.test_update_manifest scripts.test_sign_update_manifest
```

签名测试需要 OpenSSL；没有 OpenSSL 时对应测试显式跳过，不代表签名通过。原生下载与安装必须另行手动验收。
