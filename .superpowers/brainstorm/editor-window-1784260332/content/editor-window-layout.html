文件编辑器窗口交互方案

目标：编辑文件时，原 SSH 终端保持可见、可点击、可输入；编辑器可独立拖动和调整大小。

AShell — SSH: production-01
root@server:~# tail -f app.log
SSH 仍可正常输入和操作
config.yaml — AShell Editor　　— □ ×
1　server:
2　　port: 8080
3　　debug: false

独立窗口，可拖动、缩放、切换焦点

A. 独立原生窗口（推荐）

编辑器拥有自己的系统窗口和焦点。SSH 主窗口不加遮罩、不进入模态状态，两边可自由切换操作。

AShell — 同一个系统窗口
root@server:~#
浮动编辑面板
可在应用内部拖动，但不能拖出 AShell 主窗口。

B. 主窗口内浮动面板

也能保证 SSH 可操作，但受主窗口边界限制，不是真正独立窗口，系统任务栏中也不会单独显示。

AShell — 固定分栏
root@server:~#

SSH 终端
config.yaml

文件编辑器

C. 固定分栏

SSH 与编辑器同时可用，但编辑器不能随意拖动，会占用终端的固定显示空间。

建议选择 A。当前实现是全屏绝对定位遮罩，会拦截主窗口交互；改为独立 GPUI 原生窗口后，编辑器与 SSH 的输入焦点、生命周期和渲染树完全分离。
